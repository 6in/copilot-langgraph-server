## Overview

v5.0 は「Copilot ベースのシングル LLM チャット」から「MCP ツールエコシステム + 多様な推論パターンを備えたエージェントプラットフォーム」への拡張。FastMCP Docker サービスで立ち上げた MCP サーバー基盤上に 6 つのツール (ping / web_search / db_query / claude_code / execute_python / get_current_datetime) を統合し、LangGraph bind_tools + ToolNode で ReAct ループを実現、CodeAct パターンで Python サンドボックス実行まで通した。config/mcp_tools.yaml を single source of truth とし、`scripts/generate_mcp_artifacts.py` が Python helper / JS カタログ / docs を決定論的に自動生成、pre-commit hook で drift を検知する仕組みまで整備した。Phase 31 で stdout JSONL 1 行 1 span の observability 基盤 (OTEL span-like) を導入、3 経路 (ToolEnabledSubAgent / CodeAct / iframe RPC) の実行トレースを統一。URL ルーティング (React Router v7) とユーザー選択モデル伝播 (model_override) も合わせて UX を底上げ。最後に ADR カタログ化 + patterns.md で設計知識を GSD プランニングから自動参照できる状態に。

## Milestone Summary

### Decimal Phases

- **Phase 31.1:** v5.0 milestone cleanup — Nyquist VALIDATION backfill + Phase 30 VALIDATION.md 遡及作成 (inserted after Phase 31 for archive readiness)

### Key Accomplishments

1. **MCP ツールエコシステム確立** (Phase 20 / 23 / 24 / 30) — FastMCP Docker 基盤の上に 6 ツール実装 (ping / web_search / db_query / claude_code / execute_python / get_current_datetime)、`config/mcp_tools.yaml` single source of truth + `scripts/generate_mcp_artifacts.py` の決定論的自動生成 + pre-commit drift 検知
2. **LangGraph ↔ Copilot を bind_tools + ReAct で統合** (Phase 21 / 22) — Copilot SDK は bind_tools 未対応だったため「プロンプトエンジニアリング + JSON 解析」方式で `ChatCopilot.bind_tools()` を実装、ToolEnabledSubAgent を mini ReAct グラフとして構築、Tavily Web 検索で end-to-end 動作確認
3. **CodeAct + AskUserQuestion の高度対話パターン** (Phase 27 / 28) — LLM が Python コードを生成し AST allowlist + メモリ制限 + タイムアウト付き sandbox で実行するループ、AI が構造化選択肢を提示する AUQ プロトコルを 5 アプリ全てに展開
4. **observability 基盤 — 新規 infra ゼロで実行可視化** (Phase 31) — stdout JSONL 1 行 1 span の OTEL span-like スキーマ、`trace_id = RPCContext.correlation_id`、3 経路 (ToolEnabledSubAgent / CodeAct / iframe RPC) 統合、`scripts/trace_query.py` CLI + jq レシピで運用完結。既存 `audit_log` テーブルを退役
5. **UX 底上げ: URL ルーティング + ユーザーモデル伝播** (Phase 25 / 29) — React Router v7 でスレッド共有 URL 対応、SuperChat でユーザー選択モデルを AGENT.md デフォルトより優先し 4 種 SubAgent 全てで model_override 伝搬
6. **設計知識の再利用可能化** (Phase 26 + 継続) — 30+ ADR を 7 カテゴリの `docs/adr/INDEX.md` と `.planning/patterns.md` に分離し、`canonical_refs` 経由で GSD plan-phase が自動参照。v5.0 期間中に 27 本の新規 ADR を追加 (ADR-0020 〜 0047)

### Key Decisions

- **bind_tools プロンプト方式 (Phase 21)** — Copilot SDK が native tool-calling 未対応のため、system prompt にツールスキーマを注入して LLM 出力から JSON を抽出するアプローチで妥協 (ADR-0021)
- **MCP transport = streamable-http 固定 (Phase 20)** — stdio は Docker 間不可、sse はセッションアフィニティ問題あり
- **CodeAct = 直接実行 (Phase 28)** — ReAct ループを経由せず、コード生成 → sandbox 実行 → 結果観察を `execute_python` ツール 1 本で完結 (ADR-0041)
- **observability = stdout JSONL、外部集約基盤なし (Phase 31)** — 社内 200 名規模には OTEL Collector / Loki / Tempo 等は過剰、docker logs + `scripts/trace_query.py` で十分 (ADR-0045)
- **MCP single-source-of-truth (Phase 30)** — YAML 宣言 → 自動生成スクリプトで Python helper / JS カタログ / docs を全生成、手書きファイルと物理的に分離して pre-commit drift 検知 (ADR-0044)
- **Decimal phase for bookkeeping (Phase 31.1)** — milestone archive 直前の帳簿整合作業を独立 decimal phase で集約するパターンを確立 (ADR-0047)

### Issues Resolved

- 3 silent failures caught by integration check gate (Phase 31, ADR-0046) — Python logging root level / LangGraph checkpointer state 復元 / route→worker シグネチャ不整合。全て unit test 60/60 green の後に捕捉、以降は phase 完了前に docker compose 実環境での 1 経路以上 integration check を必須化
- Canvas iframe RPC 経路で trace_id が伝搬しない問題 (Phase 31-05) — route に `correlation_id` を追加、handler に request span を発行
- SuperChat 白画面バグ (Phase 28 間) — `BaseMessage.content` が list で返る ToolMessage を ReactMarkdown が object として描画しようとする問題、defense-in-depth で正規化 (ADR-0043)
