## Phase 24 MCP-03 の narrowing について

Phase 24 の 24-VERIFICATION.md は `status: gaps_found` を記録している。これは MCP-03 要件 (`config/mcp_tools.yaml` でツール名 → MCP メソッドのマッピングを管理) を per-agent allowlist にまで拡張するかを検討した際、CONTEXT.md D-02 で「ToolRegistry による名前セット検証 (bidirectional check) のみ」に narrowing する判断をしたため。**functional gap ではなく、scope 縮小の記録**。per-agent 制御は AGENT.md の `tools:` field で既に達成されており、追加の yaml 宣言は不要と判断された。

将来 Phase 30 で config/mcp_tools.yaml に sandbox_exposed / privileged などのメタデータを追加したため、今後の phase で allowlist 化を再検討する余地はある (backlog 候補)。
