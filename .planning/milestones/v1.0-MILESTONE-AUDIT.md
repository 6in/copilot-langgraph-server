### Integration Warnings

**1. marked.js version mismatch (CHAT-03 — verify)**

- `static/index.html:96` loads `marked@9.1.6`
- `static/app.js:16-21` comment says "v17 UMD global", uses `const { Marked } = globalThis.marked`
- **Assessment:** Phase 3 and 4 human checkpoints completed without reported errors. The `Marked` class has been exported in the marked UMD bundle since v4+. This is most likely a stale comment, not a runtime break. **Action required:** confirm `{ Marked }` is available in marked@9 UMD bundle in-browser, then either update CDN to marked@17 or remove the misleading v17 comment.

**2. test_sse_done_signal CI blocker (ASYNC-04)**

- `tests/test_sse.py::test_sse_done_signal` hangs indefinitely
- Root cause: test mocks `register_sse` to return a queue (asyncio.Queue pattern) but production `stream_job` polls Redis directly via `job_store.get()` — `register_sse` is never called
- The `asyncio.sleep(1)` in the Redis-polling generator + ASGI transport's synchronous response collection causes an infinite loop
- **Fix (test only, no production change):** Replace `side_effect` on `mock_job_store.get` to return `None` then `{"status":"done","result":"hi"}`, remove `register_sse`/`unregister_sse` assertions

**3. Dead code: queue-based SSE notification path**

- `JobStore.register_sse`, `unregister_sse`, and `notify()` queue write are never called in production
- `WebNotifier.done()` calls `job_store.notify()` but no queue is ever registered cross-process → always a no-op
- Tech debt, not a functional gap — Redis polling works correctly
