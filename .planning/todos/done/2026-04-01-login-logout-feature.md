## Problem

現在のアプリはログイン（Device Flow OAuth）を初回起動時に行うが、ログアウト（ログオフ）操作の手段がない。
セッションを切り替えたい場合や、認証トークンを無効化したい場合に対応できない。

具体的に欠けている機能:
- UI からのログアウトボタン / エンドポイント
- サーバー側でのトークン無効化 or ローカルトークンファイル削除
- ログアウト後の再ログイン（Device Flow 再起動）フロー

## Solution

TBD — 以下のアプローチが考えられる:

1. Web UI にログアウトボタンを追加 → `/auth/logout` POST エンドポイントを呼ぶ
2. バックエンドで `~/.copilot_sdk/token.enc` を削除し、セッションをリセット
3. 次回リクエスト時（またはページリロード時）に Device Flow を再トリガーする仕組みを追加
