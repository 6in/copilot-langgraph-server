## Problem

React版チャットUIにおいて以下の3つのUI改善が必要:

1. **チャット履歴サイドバーの折りたたみ** — 現在、履歴パネルは常に表示されており折りたためない。小さい画面やチャットに集中したい場合に不便。
2. **チャットタイトルの変更＆保存** — スレッドのタイトルを編集・保存できない。デフォルトタイトル（thread_id や最初のメッセージなど）のまま固定されている。
3. **チャットエリアのマウスによるリサイズ** — 履歴パネルとチャットエリアの境界をドラッグしてリサイズできない。固定レイアウトのみ。

## Solution

- 履歴サイドバーにトグルボタンを追加し、折りたたみ状態を状態管理（useState）で制御する
- タイトル表示部分をダブルクリックまたは編集アイコンでインライン編集可能にし、バックエンド API でスレッドメタデータとして保存する
- 履歴パネルとチャットエリアの間にドラッグ可能なリサイザー（divider）を実装し、マウスドラッグでパネル幅を変更できるようにする
