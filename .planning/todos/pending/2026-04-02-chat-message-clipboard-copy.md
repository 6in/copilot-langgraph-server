## Problem

React版チャットUIでメッセージをコピーする手段がない。以下の2つのユースケースが未対応:

1. **個々のメッセージのコピー** — 特定のAI応答やユーザー発言をすぐにクリップボードにコピーしたい。現在はテキスト選択→右クリックコピーしかない。
2. **会話全体をMarkdown表形式でコピー** — スレッド全体をドキュメントや共有用に一括エクスポートしたい。Markdown の表（`| Role | Message |`形式）でクリップボードに入れられると便利。

## Solution

- 各メッセージにホバー時表示の「コピー」ボタン（アイコン）を追加し、`navigator.clipboard.writeText()` でメッセージ本文をコピーする
- チャットエリア上部またはツールバーに「会話全体をコピー」ボタンを追加し、全メッセージを以下のMarkdown表形式に変換してコピーする:

```
| Role | Message |
|------|---------|
| User | ... |
| Assistant | ... |
```

- コピー成功時はボタンを一時的に「Copied!」表示などでフィードバックを出す
