## Problem

ThreadSidebar のスレッド一覧がフラットなリストで、日付順に並んでいるだけ。スレッド数が増えると目的のスレッドを探しにくく、古いスレッドが画面を占有してスクロール量が増える。

## Solution

日付ベースのグループ区切り線と、古いスレッドの折りたたみ機能を追加:

### 1. 日付グループ区切り線

スレッドリストを日付グループに分割し、区切り線 + ラベルを表示:

| グループ | 条件 |
|----------|------|
| 今日 | 当日作成 |
| 昨日 | 1 日前 |
| 今週 | 2〜7 日前 |
| 先週 | 8〜14 日前 |
| それ以前 | 15 日以上前 |

各グループの先頭に薄い区切り線 + グループ名ラベル（「今日」「昨日」等）を表示。

### 2. 古いスレッドの折りたたみ

- 「それ以前」グループはデフォルトで折りたたみ（collapsed）
- クリックで展開、再クリックで折りたたみ
- 折りたたみ時は「それ以前 (N 件)」と件数を表示
- 展開時に遅延ロード（API 側のページネーション）を検討 — 件数が多い場合のパフォーマンス対策

### 3. API 側の検討

現在の `GET /api/chat/history` はスレッド全件を返している可能性あり。件数が増えた場合:
- `?limit=50&before=<timestamp>` のようなカーソルベースページネーションを追加
- 初回は直近 2 週間分のみ取得、「それ以前」展開時に追加取得

### スタイル

- 区切り線: `border-top: 1px solid var(--border-color)` + 中央ラベル（ChatGPT / Claude.ai 風）
- 折りたたみ: `▶ それ以前 (12 件)` / `▼ それ以前`
- dark / light 両対応（theme.css の CSS 変数を利用）
