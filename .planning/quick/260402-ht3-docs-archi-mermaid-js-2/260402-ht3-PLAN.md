<!-- Actual architecture from codebase analysis: -->

Chat message flow:
1. Frontend POST /api/chat (JWT cookie auth) -> FastAPI chat route
2. chat route extracts github_token from JWT, enqueues arq job with arq_redis.enqueue_job("process_chat", ...)
3. Returns ChatAsyncResponse(job_id, thread_id) immediately
4. Frontend opens EventSource to GET /api/chat/{job_id}/stream (SSE)
5. Worker (separate process) picks up job: creates ChatCopilot(github_token=..., model=...)
6. Worker opens AsyncPostgresSaver -> build_graph(llm, checkpointer) -> graph.ainvoke()
7. LangGraph chatbot_node calls llm.ainvoke(messages) -> ChatCopilot._agenerate()
8. ChatCopilot._ensure_client() creates CopilotClient(SubprocessConfig) -> start() (JSON-RPC subprocess)
9. CopilotClient.create_session(model=...) -> session.send_and_wait(prompt) -> GitHub Copilot API
10. Response flows back: Copilot -> SDK -> ChatCopilot -> LangGraph -> worker
11. Worker: job_store.save_result(job_id, text) to Redis, then notifier.done()
12. SSE endpoint polls job_store.get(job_id), detects status:"done", sends SSE done event
13. Frontend receives SSE done -> GET /api/job/{job_id} -> renders result

Auth flow (GitHub Device Flow):
1. Frontend POST /api/auth/start -> CopilotAuthManager.start_device_flow()
2. httpx POST https://github.com/login/device/code -> returns user_code, verification_uri, device_code
3. Frontend displays user_code + verification_uri link
4. User opens link in browser, enters code, authorizes on GitHub
5. Frontend polls GET /api/auth/poll?flow_id=... every 5 seconds
6. auth route calls CopilotAuthManager.check_device_flow(device_code)
7. httpx POST https://github.com/login/oauth/access_token -> authorization_pending or access_token
8. On success: create_jwt(token), set httpOnly session cookie
9. Frontend receives {done: true}, stores auth state

Docker services:
- postgres (pgvector/pgvector:pg17): healthcheck pg_isready, volume postgres-data
- redis (redis:7-alpine): volume redis-data, no host port
- api (uv:python3.12-bookworm-slim): port 8000:8000, depends postgres+redis, mounts .:/app + ~/.copilot_sdk
- worker (uv:python3.12-bookworm-slim): no host port, depends postgres+redis, mounts .:/app + ~/.copilot_sdk
- frontend (node:22-alpine from ./frontend/Dockerfile): port 5173:5173, env API_TARGET=http://api:8000, depends api

**Diagram 1: Chat Message Flow (メッセージ送信〜AIレスポンス返却)**

Participants (left to right):
- Frontend (React/Vanilla JS)

- Redis

- LangGraph

- CopilotClient (JSON-RPC subprocess)
- GitHub Copilot

Sequence:
1. Frontend ->> FastAPI: POST /api/chat {message, thread_id} (JWT cookie)
2. FastAPI ->> FastAPI: decode JWT, extract github_token
3. FastAPI ->> Redis: arq enqueue_job("process_chat", job_id, thread_id, prompt, github_token)
4. FastAPI -->> Frontend: 200 {job_id, thread_id}
5. Frontend ->> FastAPI: GET /api/chat/{job_id}/stream (SSE)
6. Note over Worker,Redis: Worker picks up job from Redis queue
7. Worker ->> PostgreSQL: AsyncPostgresSaver.from_conn_string()
8. Worker ->> LangGraph: graph.ainvoke({messages: [HumanMessage(prompt)]}, config={thread_id})
9. LangGraph ->> ChatCopilot: ainvoke(messages)
10. ChatCopilot ->> CopilotClient: _ensure_client() -> start() (JSON-RPC subprocess)
11. ChatCopilot ->> CopilotClient: create_session(model) -> send_and_wait(prompt)
12. CopilotClient ->> GitHub Copilot: JSON-RPC request
13. GitHub Copilot -->> CopilotClient: AI response
14. CopilotClient -->> ChatCopilot: response.data.content
15. ChatCopilot -->> LangGraph: ChatResult(AIMessage)
16. LangGraph ->> PostgreSQL: save checkpoint (message history)
17. LangGraph -->> Worker: result {messages}
18. Worker ->> Redis: job_store.save_result(job_id, text) [FIRST]
19. Worker ->> Redis: notifier.done() [THEN]
20. Note over FastAPI: SSE polls job_store.get(job_id)
21. FastAPI -->> Frontend: SSE data: {status: "done"}
22. Frontend ->> FastAPI: GET /api/job/{job_id}
23. FastAPI ->> Redis: job_store.get(job_id)
24. Redis -->> FastAPI: {status: "done", result: text}
25. FastAPI -->> Frontend: {status: "done", result: text}

**Diagram 2: GitHub Device Flow Authentication (認証フロー)**

Participants:
- Frontend
- FastAPI
- CopilotAuthManager
- GitHub (github.com)
- User (Browser)

Sequence:
1. Frontend ->> FastAPI: POST /api/auth/start

3. CopilotAuthManager ->> GitHub: POST /login/device/code {client_id, scope:read:user}
4. GitHub -->> CopilotAuthManager: {user_code, verification_uri, device_code}
5. CopilotAuthManager -->> FastAPI: flow_data
6. FastAPI ->> FastAPI: store device_code keyed by flow_id

14.   GitHub -->> CopilotAuthManager: authorization_pending OR access_token
15.   alt authorization_pending
16.     FastAPI -->> Frontend: {done: false}
17.   else access_token received
18.     CopilotAuthManager ->> CopilotAuthManager: save_token() (encrypt to disk)
19.     FastAPI ->> FastAPI: create_jwt(token)
20.     FastAPI -->> Frontend: Set-Cookie: session=JWT (httpOnly) + {done: true}
21.   end
22. end
