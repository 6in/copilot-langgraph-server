  <name>Task 1: static/iframe-rpc.js — Promise ベース RPC クライアントライブラリ作成</name>
  <files>static/iframe-rpc.js</files>
  <action>
Create `static/iframe-rpc.js` that defines a global `RPC` object on `window`.

Implementation details:

1. IIFE で即時実行、`window.RPC` にオブジェクトを代入する

2. 内部に pending map: `Map<string, {resolve, reject, timer}>` を保持

3. `window.addEventListener('message', handler)` でレスポンス受信:
   - `e.data.jsonrpc === '2.0'` かつ `e.data.id` が pending map にある場合のみ処理
   - pending のタイマーを clearTimeout
   - `e.data.result === false` の場合は reject(new Error(e.data.error || 'RPC failed'))
   - それ以外は resolve(e.data) — 呼び出し側が `.result`, `.responseText`, `.rows` 等にアクセスできる

4. 内部ヘルパー `_call(method, params, timeoutMs)`:
   - `id = crypto.randomUUID()`
   - Promise を作成し pending map に登録
   - `parent.postMessage({jsonrpc:'2.0', id, method, params}, '*')` で送信
   - timeoutMs 後に reject(new Error('RPC timeout')) + pending map から削除

5. 公開 API:
   - `RPC.ai(prompt)` → `_call('ai', {prompt}, 60000)`
     - prompt は string。返り値の Promise は `{result: true, responseText: "..."}` または reject
   - `RPC.query(poolName, sql, params)` → `_call('query', {pool_name: poolName, sql, params}, 30000)`
     - params はオプション。返り値の Promise は `{result: true, rows: [...]}` または reject
   - `RPC.call(method, params, timeoutMs)` → `_call(method, params, timeoutMs || 60000)`
     - 汎用メソッド。将来の拡張ポイント

6. JSDoc コメントで各メソッドの引数・戻り値を記述する

7. ES5 互換は不要（srcDoc iframe は最新ブラウザ前提）。ただし import/export は使わない（グローバル変数方式）。

注意: CanvasPane の handleIframeMessage は `e.data.result === false` をエラーケースとして返す。
ライブラリ側もこの規約に合わせ、`result === false` のとき reject する。

<task type="auto">
  <name>Task 2: CanvasPane.tsx — iframe-rpc.js のインライン注入</name>
  <files>frontend/src/components/CanvasPane.tsx</files>
  <action>
CanvasPane.tsx に以下の変更を加える:

1. **State 追加**: `const [rpcScript, setRpcScript] = useState<string | null>(null);`

2. **fetch useEffect 追加** (deps=[]):
   ```
   useEffect(() => {
     fetch(`${appBase}/iframe-rpc.js`)
       .then(r => { if (!r.ok) throw new Error(`${r.status}`); return r.text(); })
       .then(code => setRpcScript(code))
       .catch(err => console.warn('[CanvasPane] Failed to load iframe-rpc.js:', err));
   }, [appBase]);
   ```
   - appBase を deps に含める（VITE_APP_BASE は実行中に変わらないが lint 規約上必要）
   - fetch 失敗時はコンソール警告のみ — Canvas アプリは動くが RPC は使えない

3. **注入ヘルパー関数** `injectRpcScript(html: string, script: string): string`:
   - `<head>` タグがある場合: `<head>` の直後（`<head>` または `<head ...>` の閉じ `>` の後）に `<script>${script}</script>` を挿入
   - `<head>` タグがない場合: HTML 先頭に `<script>${script}</script>` を付加
   - 正規表現: `/<head(\s[^>]*)?>/ ` でマッチ、replace で挿入
   - この関数はコンポーネント外（ファイルトップレベル）に定義する（テストしやすさ + 不要な再生成を避ける）

4. **srcDoc プロパティ変更**: Preview タブの iframe の srcDoc を:
   - `rpcScript` が null でない場合: `srcDoc={injectRpcScript(htmlContent, rpcScript)}`
   - `rpcScript` が null の場合: `srcDoc={htmlContent}` （従来通り）
   - `useMemo` で `[htmlContent, rpcScript]` を deps にしてメモ化する（毎 render での文字列結合回避）

注意点:
