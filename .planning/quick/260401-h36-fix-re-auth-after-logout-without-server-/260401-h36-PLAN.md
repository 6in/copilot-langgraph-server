<objective>
Fix re-authentication after logout so users do not need to restart the server.

Purpose: Currently logout leaves ChatCopilot._client stale (non-None), so _ensure_client() short-circuits on next chat. The frontend also incorrectly tells users to restart the server. This fix resets the client on logout and updates the UI messaging.

Output: Working logout -> re-auth flow without server restart; updated frontend UX.
</objective>
