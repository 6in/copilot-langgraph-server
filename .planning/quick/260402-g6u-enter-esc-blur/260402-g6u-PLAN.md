Two changes to ThreadSidebar.tsx:

**1. Display date from `updated_at` on each thread item.**

Below the thread label `<span>`, add a secondary line showing the date parsed from `thread.updated_at` (ISO timestamp string). Format as a short locale date, e.g. `new Date(thread.updated_at).toLocaleDateString()`. Use a smaller, muted font (fontSize 0.7rem, color #999). Wrap the label+date in a flex column container so they stack vertically within the existing row layout.

**2. Fix the Escape-cancel-then-blur-saves bug.**

Current bug: pressing Escape calls `cancelEdit()` which sets `editingId=null`, unmounting the `<input>`. The unmount fires `onBlur`, which calls `commitEdit()`, overriding the cancel and saving the edit value.

Fix: add a `useRef<boolean>` called `cancelledRef` (initialized to `false`).
- In `cancelEdit()`: set `cancelledRef.current = true` before calling `setEditingId(null)`.
- In the `onBlur` handler: check `if (cancelledRef.current) { cancelledRef.current = false; return; }` before calling `commitEdit()`.
- In `startEdit()`: reset `cancelledRef.current = false` to ensure clean state on new edits.

This prevents the blur handler from saving when the user explicitly cancelled.
