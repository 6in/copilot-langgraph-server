## What Was Built

### scripts/lib/backup-common.sh

- `resolve_env "dev|prod"` — COMPOSE_PROJECT / COMPOSE_FILES / VOL_* をグローバル export + volume 実在確認
- `compose <args>` — `-p PROJECT $COMPOSE_FILES` を自動付与するラッパー
- `log/warn/err` — ANSI カラー付き timestamp ログ
- `confirm "prompt"` — `ASSUME_YES=1` または `-y` で skip 可能な確認プロンプト
- `require_cmd` — コマンド存在チェック

### scripts/db-backup.sh

- `--env dev|prod` / `--out <dir>` / `--stop-services` / `--no-compress` / `-y`
- PostgreSQL: `compose exec -T postgres pg_dump | gzip → postgres.sql.gz`
- thread-files / claude-code-outputs: `docker run --rm -v busybox tar czf`
- Canvas 静的: `tar czf canvas-static.tar.gz -C ./static apps/`
- MANIFEST.json: sha256sum + stat -c '%s' でファイル情報を記録
- ERR trap で途中失敗時に DEST を自動削除

### scripts/db-restore.sh

- `<backup-dir>` (positional) / `--env` / `-y` / `--no-canvas-rebuild`
- MANIFEST.json から env 自動推定 (jq 使用)
- 確認プロンプト必須 (`-y` で skip)
- `compose down` → volume rm → `compose up -d postgres` → healthcheck wait (30 retry)
- `gunzip -c | compose exec -T postgres psql` でリストア
- busybox tar で thread-files / claude-code-outputs 展開
- Canvas dual-source rebuild: `SELECT app_id, encode(convert_to(html,'UTF8'),'base64') FROM canvas_apps WHERE deployed = true` → `base64 -d | sed "s|\$URL_PREFIX|${APP_PREFIX}|g"` → index.html 書き出し
- `compose up -d` で全サービス再開

### scripts/db-backup-prune.sh

- `--keep <N>` (default 14) / `--out <dir>` / `--dry-run` / `-y`
- `find ... -name '????????-??????' | sort` で YYYYMMDD-HHMMSS 形式ディレクトリを列挙
- 末尾 N 個以外を削除 (dry-run は一覧表示のみ)
