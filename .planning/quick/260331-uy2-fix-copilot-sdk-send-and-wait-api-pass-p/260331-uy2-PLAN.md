<objective>
Fix the incorrect `send_and_wait` call argument in `ChatCopilot._agenerate`.

The SDK 0.2.0 signature is `send_and_wait(self, prompt: str, *, ...)`.
The current code passes a dict `{"prompt": prompt}` where the SDK expects a
plain string. This causes a runtime type error on every real invocation.

Purpose: Unblock real Copilot API calls — the provider is broken as shipped.
Output: Corrected `copilot.py` and a regression test asserting the string call.
</objective>
