## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| enqueue-before-insert | `enqueue_job`をスレッドのDB INSERT前に呼んでいた。ワーカーが`_get_gem_info`を呼ぶ前にコミットが完了していないため`gem_type=None`になりシステムプロンプトが適用されなかった | blocking | `chat.py`で必ずthreads upsert→commit→enqueue_job の順を守る |
| missing-app-seed | 新しい`app_id`（例: `canvas`）を`applications`テーブルへのseedに追加し忘れると外部キー制約でINSERTが`except`で握りつぶされ無音で失敗する | advisory | `main.py`のlifespan初期化のseed INSERTに必ず追加 |
