## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| enqueue-before-insert | `enqueue_job`をスレッドのDB INSERT前に呼んでいた。ワーカーが`_get_gem_info`を呼ぶ前にコミットが完了していないため`gem_type=None`になりシステムプロンプトが適用されなかった | blocking | `chat.py`で必ずthreads upsert→commit→enqueue_job の順を守る |
| srcdoc-cors-null-origin | srcdoc iframe はオリジンが null になるため外部 ESM import が CORS でブロックされる | advisory | FastAPI /js/ ルートで Access-Control-Allow-Origin: * を返す（実装済み） |
