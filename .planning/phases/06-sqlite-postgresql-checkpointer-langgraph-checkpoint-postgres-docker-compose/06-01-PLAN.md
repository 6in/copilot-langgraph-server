**app/jobs/worker.py changes:**

1. Replace import: `from langgraph.checkpoint.sqlite.aio import AsyncSqliteSaver` with `from langgraph.checkpoint.postgres.aio import AsyncPostgresSaver`
2. Replace `DB_PATH = os.getenv("CHAT_DB_PATH", "./data/chat.db")` with `DB_URI = os.getenv("DATABASE_URL", "postgresql://postgres:postgres@localhost:5432/postgres?sslmode=disable")`
3. In `process_chat`, replace `async with AsyncSqliteSaver.from_conn_string(DB_PATH) as checkpointer:` with `async with AsyncPostgresSaver.from_conn_string(DB_URI) as checkpointer:`
4. Add `await checkpointer.setup()` call inside the worker's `startup(ctx)` hook to prevent race condition when worker receives jobs before API lifespan completes (per RESEARCH.md open question 1). This is idempotent — safe to call on every startup, costs one extra DB round-trip. Implementation: in the `async def startup(ctx)` function, open a temporary `AsyncPostgresSaver.from_conn_string(DB_URI)` context and call `await checkpointer.setup()`, then close it. The worker startup hook runs once before any jobs are processed.

**app/graph/builder.py docstring update:**

1. Update the `checkpointer` parameter docstring from `MemorySaver (tests) or AsyncSqliteSaver (production).` to `MemorySaver (tests) or AsyncPostgresSaver (production).`
