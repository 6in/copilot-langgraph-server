**list_threads route rewrite (`GET /api/threads`):**

Replace the entire `list_threads` function body. Use `request.app.state.db_uri` instead of `request.app.state.db_path`. The new implementation:

```python
@router.get("/threads")
async def list_threads(request: Request):
    """List existing threads sorted by latest activity (SESS-02 front-loaded).

    Direct SQL against AsyncPostgresSaver's checkpoints table via psycopg.
    LangGraph's alist() requires a thread_id filter — no 'list all' API.
    """
    db_uri = request.app.state.db_uri
    threads: list[ThreadInfo] = []

    try:
        async with await psycopg.AsyncConnection.connect(db_uri, row_factory=dict_row) as conn:
            async with conn.cursor() as cur:
                await cur.execute(
                    """SELECT thread_id, MAX(checkpoint_id) as latest
                       FROM checkpoints
                       WHERE checkpoint_ns = ''
                       GROUP BY thread_id
                       ORDER BY latest DESC
                       LIMIT 50"""
                )
                rows = await cur.fetchall()

        for row in rows:
            thread_id = row["thread_id"]
            checkpoint_id = row["latest"]
            label = f"Chat {thread_id[:8]}"
            threads.append(ThreadInfo(
                thread_id=thread_id,
                updated_at=str(checkpoint_id),
                label=label,
            ))
    except Exception:
        # DB may not be ready or tables may not exist yet — return empty list
        pass

    return threads
```

**delete_thread route rewrite (`DELETE /api/threads/{thread_id}`):**

Replace the entire `delete_thread` function body. Use `checkpointer.adelete_thread()` instead of raw SQL:

```python
@router.delete("/threads/{thread_id}", status_code=204)
async def delete_thread(thread_id: str, request: Request):
    """Delete a thread and all its checkpoints from PostgreSQL.

    Uses AsyncPostgresSaver.adelete_thread() which handles all related
    tables (checkpoints, checkpoint_blobs, checkpoint_writes) atomically.
    """
    checkpointer = request.app.state.checkpointer

    try:
        await checkpointer.adelete_thread(thread_id)
    except Exception:
        # Silently succeed if thread doesn't exist or DB is unreachable
        pass
```
