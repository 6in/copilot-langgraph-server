`scripts/generate_mcp_artifacts.py` を新規作成する。以下の関数構成で実装:

- `load_tools()` — config/mcp_tools.yaml を `yaml.safe_load` で読み込む
- `_format_arg(arg: dict) -> str` — `python_wrapper.args[*]` を `"name: type"` or `"name: type = default"` にフォーマット
- `_generate_wrapper_body(tool: dict) -> str` — `result_transform.mode` により本体コードを生成（passthrough / extract_key / web_search_results の 3 モード）
- `build_helper(tools) -> str` — mcp_helper.py 全文を生成
- `build_js(tools) -> str` — tool-catalog-generated.js 全文を生成
- `build_docs(tools) -> str` — docs/mcp-tools.md 全文を生成
- `write_all(tools) -> list[Path]` — 3 ファイルをディスクへ書き出す
- `check_all(tools) -> int` — drift 検知。差分あれば `difflib.unified_diff` を stderr に出力し 1 を返す
- `main() -> int` — argparse + 分岐

**定数:**
```python
ROOT = Path(__file__).resolve().parent.parent
YAML_PATH = ROOT / "config" / "mcp_tools.yaml"
HELPER_PATH = ROOT / "mcp_server" / "tools" / "mcp_helper.py"
JS_PATH = ROOT / "static" / "js" / "tool-catalog-generated.js"
DOCS_PATH = ROOT / "docs" / "mcp-tools.md"
```

**DO NOT EDIT ヘッダー (3 種類):**
```
# Python:
# DO NOT EDIT — auto-generated from config/mcp_tools.yaml by scripts/generate_mcp_artifacts.py
# To regenerate: python3 scripts/generate_mcp_artifacts.py --target helper

# JS:
// DO NOT EDIT — auto-generated from config/mcp_tools.yaml by scripts/generate_mcp_artifacts.py
// To regenerate: python3 scripts/generate_mcp_artifacts.py --target js

# Markdown:
<!-- DO NOT EDIT — auto-generated from config/mcp_tools.yaml by scripts/generate_mcp_artifacts.py -->
<!-- To regenerate: python3 scripts/generate_mcp_artifacts.py --target docs -->
```

**末尾改行規約（重要 — drift 検知の偽陽性回避のため厳守）:**

`build_helper()` / `build_js()` / `build_docs()` はいずれも生成文字列の**末尾に単一の `\n`** を付与して返す。実装例:

```python
def build_helper(tools) -> str:
    lines = [...]  # ヘッダー + docstring + import + 各関数
    return "\n".join(lines) + "\n"
```

または内部で組み立てたテキストに対して `return text.rstrip("\n") + "\n"` で正規化する。`build_js` / `build_docs` も同様に末尾が `\n` 1 文字で終わることを保証する。

`write_all()` が `Path.write_text()` でディスクに書き出す際も、返値をそのまま渡せば末尾改行が維持される。

`check_all()` は各 `build_*` の返値と `read_text()` で読み込んだファイル内容を**バイト完全一致**（`==`）で比較する。末尾改行の有無（例: `\n` 2 個 vs 1 個、あるいは末尾改行なし）だけの差分も drift として検出する。

**build_helper の出力構造（順序固定）:**
1. DO NOT EDIT ヘッダー（2 行）
2. module docstring（3-5 行、`config/mcp_tools.yaml の python_wrapper ブロックから自動生成` 明記）
3. `from mcp_helper_utils import _call_tool, _clean_content  # noqa: F401`
4. 空行 × 2
5. 各 python_wrapper ツールについて、以下を `\n\n\n`（3 行改行）で連結:
   - `def <function_name>(<args>) -> <return_type>:`
   - インデント済み docstring（`"""` で囲む）
   - `_generate_wrapper_body(tool)` が生成した本体
6. **末尾に `\n` を 1 個付与して return**

**_generate_wrapper_body の 3 分岐:**

(a) 引数なし & passthrough (ping / get_current_datetime):
```
    return _call_tool("<mcp_name>")
```

(b) 引数あり & extract_key (db_query):
```
    result = _call_tool("db_query", {"sql": sql, "pool_name": pool})
    if isinstance(result, dict):
        if "error" in result:
            return [{"error": result["error"]}]
        return result.get("rows", [result])
    return [{"error": "unexpected response"}]
```

(c) 引数あり & web_search_results (web_search):
```
    result = _call_tool("web_search", {"query": query})
    if isinstance(result, dict):
        if "error" in result:
            return [{"error": result["error"]}]
        raw_results = result.get("results", [result])
        for r in raw_results:
            if "content" in r:
                r["content"] = _clean_content(r["content"])
        return raw_results
    return [{"error": "unexpected response"}]
```

**build_js の出力構造:**
1. DO NOT EDIT ヘッダー
2. 空行
3. JSDoc ブロック（`/** ... */`）— 表見出し + 各行 `* | name | description |`
4. `export const AVAILABLE_TOOLS = [` + 各ツール `  { name: "...", description: "...", privileged: true? },` + `];`
5. **末尾に `\n` を 1 個付与して return**

既存 `scripts/sync-tool-list-to-js.py` L26-81 のカラム計算と `json.dumps(..., ensure_ascii=False)` ロジックをほぼそのまま使う。privileged タグは description に ` [privileged]` 接尾辞を付ける（テーブルのみ）。JS オブジェクトリテラル側は `privileged: true` を追加。

**JS 出力の配列順序（厳守）:**
`build_js` の出力配列順は YAML の `tools:` エントリ順と完全一致する。具体的には以下の順序で `{ name: "..." }` オブジェクトが出現する:

**build_docs の出力構造:**
1. DO NOT EDIT HTML コメント
2. 空行
3. `# MCP Tools Catalog`
4. 概要文（`config/mcp_tools.yaml` から自動生成された旨、追加手順は `docs/mcp-tool-add-manual.md` を参照）
5. `## ツール一覧` + テーブル `| Tool | Privileged | Sandbox Helper | Description |`（Sandbox Helper 列は `mcp_helper.<fn>()` or `—`）
6. 各ツールごとに:
   - `## \`<name>\``
   - 1 行説明
   - privileged なら警告段落
   - `**Sandbox Helper:**` シグネチャ + docstring コードブロック / or `なし（...）`
7. **末尾に `\n` を 1 個付与して return**

**check_all の挙動:**
- `build_helper` / `build_js` / `build_docs` の結果と既存ファイル内容を**バイト完全一致**（`actual_text == expected_text`）で比較
- 不一致ファイルごとに `[drift] out of sync: <path>` + `difflib.unified_diff` を stderr に出力
- 存在しないファイルは `[drift] missing: <path>` として drift 扱い
- drifted なら末尾に「Fix: python3 scripts/generate_mcp_artifacts.py --target all && git add <files>」を表示して 1 を返す
- 差分なしなら 0 を返す

**argparse:**
- `--target` choices=["helper","js","docs","all"] default="all"
- `--check` action="store_true"

**実行順:**

最後に `chmod +x scripts/generate_mcp_artifacts.py` を実行して実行権限を付与する。
