## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| AI レスポンス → parseJobResult | AI 生成テキストから JSON を抽出してパースする |
| ユーザー回答 → sendMessage | ユーザー入力をテキスト化して既存チャットフローに渡す |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-27-03 | Tampering | parseJobResult (useChat.ts) | mitigate | parseAUQ 内の try-catch で不正 JSON を無視。パース失敗は plain text として扱う（silent fallback）|
| T-27-04 | Spoofing | handleQuestionSubmit (useChat.ts) | accept | ユーザー回答は既存の sendMessage 経由で送信されるため、既存の JWT 認証がそのまま適用される |
| T-27-05 | Denial of Service | pendingQuestion state | accept | pendingQuestion は 1 つのみ保持。AI が連続で質問を返しても最新のみ表示。メモリ増大リスクなし |
</threat_model>
