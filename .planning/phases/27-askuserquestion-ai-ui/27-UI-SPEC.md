## Component Inventory

### 新規作成: QuestionPanel.tsx

`frontend/src/components/QuestionPanel.tsx`

**Props インターフェース（TypeScript）:**
```typescript
export interface AUQOption {
  label: string;
  description?: string;
}
export interface AUQQuestion {
  question: string;
  header: string;
  type?: 'single' | 'multi' | 'text';
  options?: AUQOption[];
  allowFreeText?: boolean;
  placeholder?: string;
  optional?: boolean;
}
export interface AskUserQuestionPayload {
  questions: AUQQuestion[];
}
interface QuestionPanelProps {
  questions: AUQQuestion[];
  onSubmit: (answers: Record<string, string>) => void;
}
```

**locked / lockedAnswers props は省略する（D-07 による）。**

**レイアウト仕様:**
- 外側: `display: flex; flex-direction: column; gap: 16px`（md スペーシング）
- 質問ブロック: `display: flex; flex-direction: column; gap: 8px`（sm スペーシング）
- 選択肢グリッド: `display: grid; grid-template-columns: repeat(2, 1fr); gap: 8px`（sm スペーシング。旧値 6px を 8px に修正）
- **視覚的アンカー:** 「回答を送信」ボタンがパネル最下部に常時固定表示され、ユーザーの視線の焦点となる（accent #22c55e が全体の中で唯一の高彩度要素）

**ボタン状態:**
- 非選択: border `#2a2a35`（dark）/ `#d1dbe3`（light）
- 選択済み: border `#22c55e`、background `#0f1f0f`（dark）
- 送信ボタン enabled: background `#22c55e`、color `#fff`、font-weight 600
- 送信ボタン disabled: background `#1a2a1a`、color `#2a4a2a`、cursor `default`

**アクセシビリティ:**
- 選択肢ボタン: `<button>` 要素、disabled 属性で送信中無効化
- テキスト入力: `<input>` 要素、placeholder 必須
- 送信ボタン: `disabled={!canSubmit}`
- 円形インジケーター（single）: border-radius `50%`
- 角形インジケーター（multi）: border-radius `3px`

### 変更: MessageArea.tsx

**追加 Props:**
```typescript
pendingQuestion?: AskUserQuestionPayload | null;
onQuestionSubmit?: (answers: Record<string, string>) => void;
```

**入力エリア条件分岐ロジック:**
- `pendingQuestion` が null でない場合: `<textarea>` と Send ボタンを `<QuestionPanel>` に置換
- `pendingQuestion` が null の場合: 既存の textarea + Send ボタンを表示
- 切り替えは `chat-input-bar` div の内部で行う（div 自体は残す）

**入力エリア置換時の hint テキスト:**
- テキスト上部に「質問に回答してください」ヒントラベルを表示
- スタイル: font-size 11px、color `#9090a8`（dark）/ `#888`（light）、margin-bottom 8px

### 変更: useChat.ts

**新規状態・返値（追加のみ、削除なし）:**
```typescript
pendingQuestion: AskUserQuestionPayload | null;
handleQuestionSubmit: (answers: Record<string, string>) => void;
```

**parseJobResult 拡張: タグ検出正規表現:**
```
const AUQ_RE = /<ask_user_question>([\s\S]*?)<\/ask_user_question>/;
```
- `JSON.parse` catch ブロック内で `AUQ_RE` マッチを試みる
- マッチした場合: JSON パース成功なら `askUserQuestion` を返す、失敗なら plain text として扱う
- `handleQuestionSubmit` 内: `Object.entries(answers).filter(([, v]) => v).map(([q, a]) => \`${q}：${a}\`).join('\n')` でテキスト化

## Interaction Contract

### D-01: 入力エリア置換パターン

| 状態 | 入力エリアの表示 |
|------|--------------|
| `pendingQuestion === null` | 通常の textarea + Send ボタン |
| `pendingQuestion !== null` && `isThinking === false` | QuestionPanel（ヒント付き） |
| `isThinking === true` | 通常の textarea（disabled）※ 質問受信中は pendingQuestion は null のまま |

**遷移:**
1. AI レスポンス受信 → `parseJobResult` が `<ask_user_question>` タグを検出
2. `setPendingQuestion(auq)` → MessageArea が QuestionPanel に切り替わる
3. ユーザーが「回答を送信」クリック → `handleQuestionSubmit` 呼び出し
4. `setPendingQuestion(null)` + `sendMessage(text)` → 通常入力エリアに戻る + SSE ジョブ開始

### D-02: 質問パネル未回答時の動作

- 必須質問（`optional: false`）に未回答がある場合: 「回答を送信」ボタンを disabled にする
- hint ラベル「質問に回答してください」を入力エリア上部に常時表示（QuestionPanel 表示中のみ）
- ユーザーが Ctrl+Enter を押しても送信しない（textarea が非表示のため自然に無効）

### streamPreview とのインテグレーション

- `<ask_user_question>` タグを含む AI レスポンスが streaming 中に streamPreview に表示される可能性がある
- streamPreview の既存ロジック（最初の改行前のみ表示）により、タグ全体が表示されることは稀
- 問題が顕在化した場合の対処（低優先度）: streamPreview 内に `<ask_user_question` が含まれる場合は非表示にする

## Theme Adaptation

### ダークテーマ適用方針

QuestionPanel のスタイルは `work/uaw/AskUserQuestion.jsx` 参考実装のインラインスタイルをそのまま TypeScript 化する。参考実装はダークテーマ専用カラーで設計されており、既存プロジェクトのダークテーマトークンと整合する:

| work/uaw カラー | 対応する theme.css トークン |
|---------------|--------------------------|
| `#1e1e2e`（panel 背景） | `#1e1e2e`（cs-message-list 背景） |
| `#2a2a3e`（chat-input-bar） | `#2a2a3e`（chat-input-bar dark） |
| `#3a3a52`（border） | `#3a3a52`（border dark） |
| `#e8e8f0`（テキスト） | `#e8e8f0`（text dark） |
| `#9090a8`（muted テキスト） | `#9090a8`（muted text dark） |

**ライトテーマ対応:**
- QuestionPanel のライトテーマはフォールバックとして以下を適用する:
  - panel 背景: `#ffffff`
  - ボタン背景: `#f6f8fa`
  - ボーダー: `#d1dbe3`
  - テキスト: `#24292e`
- `useCurrentTheme()` hook で `isDark` を取得し、インラインスタイルを切り替える（既存 MessageArea と同パターン）

**theme.css への追加クラス:**
```css
/* QuestionPanel — input-bar 内ヒントラベル */
[data-theme="dark"] .question-hint-label {
  color: #9090a8 !important;
}
```
