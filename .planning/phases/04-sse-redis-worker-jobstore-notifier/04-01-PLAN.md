5. Create `app/jobs/job_store.py` with class `JobStore`:
   - `__init__(self, redis: Redis)` — store redis client, init `self.queues: dict[str, asyncio.Queue] = {}`
   - `register_sse(self, job_id: str) -> asyncio.Queue` — create Queue, store in self.queues[job_id], return it
   - `unregister_sse(self, job_id: str) -> None` — `self.queues.pop(job_id, None)`
   - `async save_result(self, job_id: str, result: str) -> None` — `await self.redis.set(f"job:{job_id}", json.dumps({"status": "done", "result": result}), ex=3600)`
   - `async notify(self, job_id: str, status: str) -> None` — if job_id in self.queues: `await self.queues[job_id].put({"status": status})`
   - `async get(self, job_id: str) -> Optional[dict]` — `raw = await self.redis.get(f"job:{job_id}")`, return `json.loads(raw) if raw else None`
   - Import from `redis.asyncio import Redis` at top
   - Import `asyncio`, `json`, `typing.Optional`

6. Create `app/jobs/notifier.py`:
   - `class BaseNotifier`: abstract with `async def progress(self, status: str) -> None: ...` and `async def done(self) -> None: ...`
   - `class WebNotifier(BaseNotifier)`:
     - `__init__(self, job_id: str, job_store: JobStore)` — store both
     - `async def progress(self, status: str)` — `await self.job_store.notify(self.job_id, status)`
     - `async def done(self)` — `await self.job_store.notify(self.job_id, "done")`
   - `def build_notifier(reply_to: dict, job_store: JobStore) -> BaseNotifier`:
     - if `reply_to["type"] == "web"`: return `WebNotifier(reply_to["job_id"], job_store)`
     - else: `raise ValueError(f"Unknown reply_to type: {reply_to['type']}")`
   - Import `from app.jobs.job_store import JobStore`
