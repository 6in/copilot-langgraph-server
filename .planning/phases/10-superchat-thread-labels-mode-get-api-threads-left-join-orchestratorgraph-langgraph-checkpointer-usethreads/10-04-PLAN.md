4. Wrap the graph build + invoke in an AsyncPostgresSaver context manager. Replace the current lines 52-60:

```python
graph = build_orchestrator_graph(registry, github_token)
initial: AgentState = { ... }
result = await graph.ainvoke(initial)
```

with:

```python
async with AsyncPostgresSaver.from_conn_string(DB_URI) as checkpointer:
    await checkpointer.setup()
    graph = build_orchestrator_graph(registry, github_token, checkpointer=checkpointer)
    config = {"configurable": {"thread_id": thread_id}}

    # Per Pitfall 2: pass input each turn; messages accumulated by checkpointer
    initial: AgentState = {
        "input": prompt,
        "output": "",
        "next": "",
    }
    result = await graph.ainvoke(initial, config=config)
```

CRITICAL per Pitfall 2 from RESEARCH.md:
- DO NOT pass `"messages": []` in initial state. The checkpointer accumulates messages via the `Annotated[list[BaseMessage], operator.add]` reducer. Passing `"messages": []` on each turn would reset the accumulated history.
- DO pass `"input": prompt` each turn (the router reads the current input).
- DO pass `config=config` with thread_id so the checkpointer loads/saves the correct thread state.
