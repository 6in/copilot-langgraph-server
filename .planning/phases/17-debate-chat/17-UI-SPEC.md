# Phase 17 — UI Design Contract

> Visual and interaction contract for Phase 17: DebateChatApp (ターン制マルチエージェント討論チャット).
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | @chatscope/chat-ui-kit-react 2.1 (existing) |
| Icon library | Unicode / emoji (existing project pattern) |
| Font | System default (inherited from chatscope) |

**Rationale:** shadcn は未導入。プロジェクトは `@chatscope/chat-ui-kit-react` + インラインスタイルパターンを一貫して使用。`DebateChatApp` は `SuperChatApp.tsx` のパターンを流用するため、新規デザインシステムは導入しない（CONTEXT.md D-11）。

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | チップ間ギャップ、インラインアイコン余白 |
| sm | 8px | 設定パネル内要素間、ラジオ/チェックボックス行間 |
| md | 16px | セクション内パディング、カード内マージン |
| lg | 24px | 設定パネルセクション間余白 |
| xl | 32px | 設定パネル全体の上下パディング |
| 2xl | 48px | ページレベルの余白（設定画面の max-width 中央揃え） |
| 3xl | 64px | 未使用（この Phase では不要） |

Exceptions:
- チップ高さ（`padding: 4px 12px` + borderRadius 16px）は既存 AgentChip / GemChip パターンを継承
- ヘッダー高さ 48px は既存 Header コンポーネント固定値を継承
- サイドバー初期幅 240px / 最小 160px / 最大 480px は既存 SuperChatApp パターンを継承
- ターン数入力フィールドは `width: 64px` 固定（数値入力のみ）

## Typography

既存コンポーネントから収集したサイズ体系を引き継ぐ（source: SuperChatApp.tsx, MenuScreen.tsx, Header.tsx）。

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px (1rem) | 400 | 1.5 |
| Label / Chip | 13px (0.82rem) | 400 (unselected) / 600 (selected) | 1.2 |
| Section heading | 20px (1.25rem) | 600 | 1.2 |
| Small / Meta | 12.5px (0.78rem) | 400 | 1.4 |

**適用ルール:**
- 設定パネルの「討論パターン」「参加者」「ターン数」ラベルは Section heading (20px, 600)
- フォームラベル（radio / checkbox テキスト）は Body (16px, 400)
- チップテキスト（エージェント名・Gem 名）は Label (13px)
- 設定パネルの補足テキスト（パターン説明など）は Small (12.5px, 400, #777 / #9090a8 dark)
- エラーメッセージ・空状態テキストは Body (16px, 400)

### Light Mode（デフォルト）

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #ffffff / #f8f9fa | チャットエリア背景、設定パネル背景、メッセージリスト |
| Secondary (30%) | #f5f5f5 / #f8f9fa | チップ行背景、サイドバー背景、カード背景 |
| Accent (10%) | #0366d6 | 選択済みエージェントチップ、primary ボタン（討論開始、延長承認） |
| Gem accent | #28a745 | 選択済み Gem チップのみ（既存 GemSelector パターン継承） |
| Header surface | #24292e | ヘッダー背景（固定） |
| Border | #d1dbe3 | カード枠線、チップ未選択枠線、仕切り線 |
| Destructive | #e05252 | エラーテキスト、削除ボタンホバー |

### Dark Mode（`[data-theme="dark"]`）

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #1e1e2e | チャットエリア背景、設定パネル背景 |
| Secondary (30%) | #2a2a3e | チップ行背景、サイドバー背景、モーダル背景 |
| Accent (10%) | #7c6ff7 | 選択済みエージェントチップ（dark）、primary ボタン（dark）、フォーカスボーダー |
| Border (dark) | #3a3a52 | カード枠線、仕切り線 |
| Text primary | #e8e8f0 | 本文テキスト |
| Text muted | #9090a8 | 補足テキスト、空状態 |
| Destructive | #e05252 | エラーテキスト（同色） |

**Accent reserved for（厳格なリスト）:**
1. 「討論を開始」ボタン（設定パネルの primary CTA）
2. 「延長する」ボタン（ターン終了後の延長承認 CTA）
3. 選択済みエージェントチップの fill 色
4. テキスト入力フォーカス時のボーダー色

Gem チップのアクセントは #28a745（green）を使い、エージェントチップ (#0366d6 blue) と視覚的に区別する。これは既存 GemSelector の確立パターン。

## Layout Specification

### 設定フェーズ（チャット開始前）

```
+--------------------------------------------------+
| Header (48px, #24292e)                           |
+--------------------------------------------------+
|                                                  |
|  DebateConfigPanel (centered, max-width: 480px)  |
|                                                  |
|  [ セクション1: 会話パターン ]                    |
|    (o) 討論 debate — A と B が交互に反論する      |
|    ( ) パネル panel — 複数エージェントが順に発言  |
|    ( ) チェーン chain — A → B → C の一方向        |
|                                                  |
|  [ セクション2: 参加者 ]                          |
|    [x] Agent A    [x] Agent B    [ ] Agent C     |
|    [x] Gem X      [ ] Gem Y                      |
|                                                  |
|  [ セクション3: ターン数 ]                        |
|    各エージェント [ 3 ] ターン                    |
|                                                  |
|  [ 討論を開始 ]  (accent #0366d6, full-width btn) |
|                                                  |
+--------------------------------------------------+
```

- 設定パネル全体の垂直中央は `padding-top: 48px` で上寄せ（コンテンツが少ない場合でも上部に配置）
- パネル幅: `max-width: 480px`, `width: 100%`, `margin: 0 auto`
- セクション間: `gap: 24px` (lg token)
- パネル外枠パディング: `padding: 32px` (xl token) — light: #fff / dark: #2a2a3e, border: 1px solid #d1dbe3

### チャットフェーズ（討論進行中）

```
+--------------------------------------------------+
| Header (48px)                                    |
+--------------------------------------------------+
| ThreadSidebar | [resize divider] | Chat Area      |
| (240px def)   |                 |                 |
|               |                 | [agent/gem row] |
|               |                 | MessageArea     |
|               |                 |   [Agent A]:... |
|               |                 |   [Agent B]:... |
|               |                 |                 |
|               |                 | [ExtensionBanner] (if turn_complete) |
|               |                 |                 |
|               |                 | [MessageInput]  |
+--------------------------------------------------+
```

- チャットフェーズのレイアウトは `SuperChatApp.tsx` と同一構造
- AgentSelector 行: エージェントチップ（blue）
- GemSelector 行: Gem チップ（green）— 0件の場合は行を非表示（既存 GemSelector パターン）

### ExtensionBanner（ターン終了後）

```
+--------------------------------------------------+
| [!] 討論が N ターン終了しました。                 |
|     延長しますか？ あと [ 3 ] ターン              |
|     [ 延長する ]  [ 終了する ]                    |
+--------------------------------------------------+
```

- 位置: MessageArea と MessageInput の間（MessageArea の最下部に sticky で表示）
- 背景: `rgba(3, 102, 214, 0.08)` (light) / `rgba(124, 111, 247, 0.15)` (dark)
- Border: `1px solid #0366d6` (light) / `1px solid #7c6ff7` (dark)
- ターン数入力: `width: 64px`, `type: number`, `min: 1`, `max: 20`
- 「延長する」ボタン: accent fill (#0366d6 / #7c6ff7)
- 「終了する」ボタン: transparent background, border #d1dbe3

## Interaction States

### 設定パネル

| State | Trigger | Visual |
|-------|---------|--------|
| Initial | ページ読み込み | パターン "debate" 選択済み、ターン数 "3" 入力済み |
| Validation error | 参加者0名で「討論を開始」押下 | `color: #e05252` エラーメッセージ「参加者を1名以上選択してください」を入力欄の上に表示 |
| Loading (agents) | エージェントリスト取得中 | 「Loading...」テキスト (0.78rem, #aaa) |
| No agents | エージェントリスト空 | 「No agents found」テキスト (0.78rem, #f0a500) |
| Submitting | 討論を開始 押下 | ボタンを `disabled`, opacity 0.6, テキスト「開始中...」 |

### チャットフェーズ

| State | Trigger | Visual |
|-------|---------|--------|
| Thinking | メッセージ送信後 SSE 待機 | 既存 TypingIndicator（chatscope 標準） |
| Turn complete | job result `status: "turn_complete"` | ExtensionBanner を表示。MessageInput は disabled |
| Extending | 「延長する」押下 | ExtensionBanner を非表示、MessageInput を enabled、再度 Thinking state へ |
| Debate ended | 「終了する」押下 | ExtensionBanner を非表示、MessageInput を disabled（または placeholder「討論が終了しました」） |
| Error | job result `status: "error"` | MessageArea に `[システム]: エラーが発生しました。再度お試しください。` を追加表示 |

## Accessibility Requirements

- すべての form 要素（radio, checkbox, number input）に `<label>` または `aria-label` を付与
- ラジオグループは `role="radiogroup"` + `aria-labelledby` でグループ化
- チェックリストは `<fieldset>` + `<legend>` でラップ
- ExtensionBanner は `role="alert"` を付与してスクリーンリーダーに通知
- 「討論を開始」ボタンの disabled 状態は `aria-disabled="true"` + `disabled` 属性を両方設定
- カラーコントラスト: 白背景 (#fff) 上の #0366d6 は WCAG AA 準拠（コントラスト比 4.56:1）
