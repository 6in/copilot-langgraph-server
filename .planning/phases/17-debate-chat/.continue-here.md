## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Worker/API プロセス分離 | arq worker と FastAPI API は別プロセス — メモリ内 Queue は共有されない。Redis Pub/Sub も `get_message()` が非ブロッキングで即 None を返すため機能しない | advisory | クロスプロセス通信は Redis データ構造（List/Hash/Sorted Set）を使いポーリングする |
| --build なしの docker compose | コードを変更後に `--build` なしで起動すると古いイメージが動き続けて変更が反映されない | advisory | コード変更後は必ず `docker compose up --build -d` |
| Docker コンテナのコードが古い | コンテナが古い commit (dc591d1: ainvoke) でビルドされていたため、その後追加した astream/turns がコンテナに入っておらず Redis に turns が書かれなかった | advisory | 変更後は必ずコンテナをリビルド。デバッグ時は `docker exec` でコンテナ内のコードを直接確認する |
| aget_state での AIMessage 型消失 | PostgreSQL チェックポインタからの逆シリアライズで AIMessage 型が失われ `_build_debate_turns` が [] を返していた | advisory | astream ループ内で直接 turns を蓄積する（in-memory の Python オブジェクトは型が保持される） |
