## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Worker/API プロセス分離 | arq worker と FastAPI API は別プロセス — メモリ内 Queue は共有されない。Redis Pub/Sub も `get_message()` が非ブロッキングで即 None を返すため機能しない | advisory | クロスプロセス通信は Redis データ構造（List/Hash/Sorted Set）を使いポーリングする。Pub/Sub は使わない |
| --build なしの docker compose | コードを変更後に `--build` なしで起動すると古いイメージが動き続けて変更が反映されない | advisory | コード変更後は必ず `docker compose up --build -d` |
