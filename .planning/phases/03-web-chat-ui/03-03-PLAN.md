**checkAuthStatus():**
```javascript
async function checkAuthStatus() {
  const resp = await fetch('/api/auth/status');
  const data = await resp.json();
  const el = document.getElementById('auth-status');

  if (data.authenticated) {
    isAuthenticated = true;
    // Green dot + "Authenticated" (UI-SPEC: Header)
    el.innerHTML = '<span style="color:#4caf50">&#9679;</span> Authenticated';
    el.className = 'auth-status authenticated';
    el.onclick = null;
    el.style.cursor = 'default';
  } else if (data.expired) {
    isAuthenticated = false;
    // D-04: "Session expired -- click to re-auth"
    el.textContent = 'Session expired \u2014 click to re-auth';
    el.className = 'auth-status expired';
    el.style.cursor = 'pointer';
    el.onclick = () => startAuthFlow();
  } else {
    isAuthenticated = false;
    // Unauthenticated: show Login button
    el.textContent = 'Login with GitHub';
    el.className = 'auth-status login-btn';
    el.style.cursor = 'pointer';
    el.onclick = () => startAuthFlow();
  }
}
```

**startAuthFlow():**
- POST `/api/auth/start`
- Show auth panel (set `display: flex`)
- Set `auth-url` href and textContent to `data.verification_uri`
- Set `device-code` textContent to `data.user_code`
- Start polling with `setInterval` every 5000ms calling `pollAuth()`

**pollAuth():**
- GET `/api/auth/poll`
- If `data.done === true`: clear interval, hide auth panel, call `checkAuthStatus()`, call `location.reload()` (D-03: auto-refresh on success)
- If `data.error` and not `done`: show error in auth panel

**Copy button:**
- `navigator.clipboard.writeText(deviceCode)` then change button text to "Copied ✓" for 2 seconds

**sendMessage():**
- Get input value, trim, return if empty
- If not authenticated: `appendMessage('error', 'You need to log in before sending messages.')` and return
- Disable input + send button (D-13: `disabled = true` + add `disabled` class)
- Call `appendMessage('user', text)` — user messages use `textContent` NOT `innerHTML` (security)
- Clear input, reset textarea height
- Call `showTyping()` (D-12)
- `fetch POST /api/chat` with `{ message: text, thread_id: activeThreadId, model: selectedModel }`
- On response: call `hideTyping()`
  - If `data.error === 'auth_expired'`: call `checkAuthStatus()` (triggers D-04 header update)
  - If `data.error` (other): `appendMessage('error', data.error)`
  - Else: `appendMessage('ai', data.reply)` — AI reply uses `md.parse()` and `innerHTML` with `.prose` class
- On network error: `appendMessage('error', 'Something went wrong. Check your connection and try again.')`
- Finally: re-enable input + send button, focus input

**appendMessage(role, content):**
- Hide empty state if visible
- Create `div.message.{role}`
- For `user`: set `textContent = content` (NOT innerHTML — XSS prevention)
- For `ai`: set `innerHTML = '<div class="prose">' + md.parse(content) + '</div>'` (Markdown rendered)
- For `error`: set `textContent = content`, add `.error` class
- Append to `#message-list`
- Scroll to bottom: `messageList.scrollTop = messageList.scrollHeight`

**showTyping() / hideTyping():**
```javascript
function showTyping() {
  const bubble = document.createElement('div');
  bubble.id = 'typing-indicator';
  bubble.className = 'message ai typing';
  bubble.innerHTML = '<span class="dot"></span><span class="dot"></span><span class="dot"></span>';
  document.getElementById('message-list').appendChild(bubble);
  bubble.scrollIntoView({ behavior: 'smooth' });
}
function hideTyping() {
  document.getElementById('typing-indicator')?.remove();
}
```
