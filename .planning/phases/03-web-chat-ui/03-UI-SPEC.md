# Phase 3 — UI Design Contract

> Visual and interaction contract for Phase 3: Web + Chat UI.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> Stack: Vanilla JS + HTML/CSS served as FastAPI StaticFiles — no build toolchain, no component library.

## Layout Contract

Source: CONTEXT.md D-05 through D-08

```
┌──────────────────────────────────────────────────────┐
│  HEADER: App name | Auth status (clickable)          │
├─────────────┬────────────────────────────────────────┤
│  SIDEBAR    │  CHAT AREA                             │
│  (240px)    │  ┌──────────────────────────────────┐  │
│  New Chat   │  │  MESSAGE LIST (scrollable)       │  │
│  ─────────  │  │  [User bubble — right-aligned]   │  │
│  Thread 1   │  │  [AI bubble — left-aligned]      │  │
│  Thread 2   │  │  [Typing indicator bubble]       │  │
│  Thread 3   │  └──────────────────────────────────┘  │
│  ...        │  ┌──────────────────────────────────┐  │
│             │  │  INPUT BAR (textarea + Send btn) │  │
│  Model      │  └──────────────────────────────────┘  │
│  [dropdown] │                                        │
└─────────────┴────────────────────────────────────────┘
```

**Layout rules:**
- Sidebar: fixed 240px width, left side, full viewport height minus header
- Header: fixed top bar, full width, 48px height
- Chat area: remaining space right of sidebar, flex-column: message list fills remaining height, input bar anchored to bottom
- Message list: `overflow-y: auto`, scrolls to bottom on new message
- Model dropdown: placed in sidebar below thread list (CONTEXT.md D-09 — planner discretion resolved to sidebar)

## Spacing Scale

Declared values (multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding |
| sm | 8px | Message bubble inner padding (vertical), button padding (vertical) |
| md | 16px | Message bubble inner padding (horizontal), input bar padding, sidebar item padding |
| lg | 24px | Section gaps within sidebar, header padding |
| xl | 32px | Sidebar width padding from edge |
| 2xl | 48px | Header height (fixed), touch target minimum |
| 3xl | 64px | Not used in v1 |

**Exceptions:**
- Input textarea: minimum height 44px (meets accessible touch target baseline)
- Message bubbles: max-width 72% of chat area width
- Sidebar fixed width: 240px (not on 8-point scale — structural layout value)

## Typography

All values apply to `static/style.css`. No external font load — system stack only.

| Role | Size | Weight | Line Height | Usage |
|------|------|--------|-------------|-------|
| Body | 15px | 400 | 1.5 | Message text, thread list items, input text |
| Label | 13px | 400 | 1.4 | Auth status text, model label, timestamp hints |
| Heading | 18px | 600 | 1.2 | App name in header |
| Code (inline) | 13px | 400 | 1.5 | Inline code within Markdown-rendered AI replies |

**Code block typography:** Pre/code blocks use `font-family: 'Menlo', 'Consolas', 'Courier New', monospace` at 13px, weight 400, line-height 1.6. These are rendered by marked.js + highlight.js — do not override highlight.js theme font.

**Font stack:** `font-family: system-ui, -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif`

## Color

Dark-leaning neutral palette appropriate for a developer tool. No light/dark toggle in v1.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#1e1e2e` | Page background, message list background |
| Secondary (30%) | `#2a2a3e` | Sidebar background, header background, input bar background |
| Accent (10%) | `#7c6ff7` | Send button, active thread highlight in sidebar, "New Chat" button |
| Surface-elevated | `#313145` | User message bubble background, thread list hover state |
| AI bubble surface | `#252535` | AI reply bubble background (slightly distinct from dominant) |
| Destructive | `#e05252` | Error inline messages only — no destructive actions exist in this phase |

**Accent reserved for:**
1. Send button background
2. "New Chat" button background
3. Active (currently selected) thread item left-border indicator
4. Auth status text color when in "authenticated" state

**Text colors:**
- Primary text: `#e8e8f0` — message body, sidebar thread names
- Secondary text: `#9090a8` — timestamps, auth status label text, model label
- Code text: inherits from highlight.js theme (use `github-dark` theme)
- Error text: `#e05252`
- Link text (Device Flow URL): `#7c6ff7` (accent), underlined

## Component Contracts

### Header (fixed top bar)

- Height: 48px
- Left: App name "Copilot Chat" — 18px, weight 600
- Right: Auth status chip — 13px, weight 400
  - **Authenticated:** text `#9090a8` — "● username" (green dot `#4caf50`)
  - **Unauthenticated:** accent button — "Login with GitHub"
  - **Expired:** text `#e05252` — "Session expired — click to re-auth" (clickable, cursor pointer) — source: CONTEXT.md D-04

### Sidebar (240px fixed)

- Top: "New Chat" button — accent background, full width minus 16px padding each side, 36px height
- Below button: thread list — scrollable, one item per thread
  - Thread item: 15px, weight 400, single line with ellipsis overflow, 40px height, 16px horizontal padding
  - Active thread: left border 3px solid accent, background `#313145`
  - Thread label: "Chat YYYY-MM-DD HH:mm" format (source: CONTEXT.md discretion — timestamp format chosen here)
- Bottom of sidebar: model selector
  - Label "Model:" at 13px, weight 400, `#9090a8`
  - `<select>` element, full width minus padding, options: gpt-4.1 (default), gpt-4o, o3 — source: CONTEXT.md D-10

### Message Bubbles

Source: CONTEXT.md D-08, D-12

- **User bubble:** right-aligned, max-width 72%, background `#313145`, border-radius 16px 16px 4px 16px, padding 8px 16px, text `#e8e8f0`
- **AI bubble:** left-aligned, max-width 72%, background `#252535`, border-radius 16px 16px 16px 4px, padding 8px 16px, text `#e8e8f0`
- **Typing indicator bubble (D-12):** left-aligned, same style as AI bubble, contains three animated dots: `●  ●  ●` pulsing with CSS keyframe (opacity 0→1→0, staggered 0.2s delay per dot)
- **Error bubble:** left-aligned, background `#2a1a1a`, border 1px solid `#e05252`, text `#e05252`, same border-radius as AI bubble
- Markdown content inside AI bubbles: rendered HTML from marked.js — apply `.prose` CSS class to scope Markdown styles without leaking to UI chrome

### Input Bar (anchored to bottom of chat area)

Source: CONTEXT.md D-13

- Background: `#2a2a3e` (secondary)
- Padding: 16px
- `<textarea>` for input: background `#1e1e2e`, border 1px solid `#3a3a52`, border-radius 8px, padding 8px 12px, min-height 44px, max-height 120px (auto-grow), font 15px/1.5, color `#e8e8f0`, resize: none
- Send button: to the right of textarea, 36px × 36px, border-radius 8px, background accent `#7c6ff7`, "Send" text 13px weight 600 white — OR use Unicode arrow symbol `→`
- **Disabled state (D-13):** textarea + send button both `opacity: 0.5`, `pointer-events: none`, `cursor: not-allowed` — applied immediately on submit, removed on response receipt

### Device Flow Auth Panel

Source: CONTEXT.md D-01, D-02, D-03

Shown full-screen overlay or replaces chat area when unauthenticated. Contains:
- Heading: "Connect to GitHub Copilot" — 18px, weight 600
- Instruction text: "Open the URL below and enter the code to authenticate." — 15px, weight 400
- URL: displayed as clickable `<a>` link, accent color, underlined, `target="_blank"` (user opens manually — no `window.open()` per D-01)
- Device code: displayed large (28px, weight 600, monospace, letter-spacing 0.2em), centered, with Copy button beside it
  - Copy button: "Copy" label, on click: writes code to clipboard, label changes to "Copied ✓" for 2s
- Status text: "Waiting for authentication..." with a subtle spinner (CSS border animation), polls every 5s (D-03)
- On success: page reloads automatically — no manual action

## Markdown Rendering Contract

Source: RESEARCH.md Standard Stack; REQUIREMENTS.md CHAT-03

Libraries loaded via CDN (no npm, no build step):
- marked.js 17.0.5: `https://cdn.jsdelivr.net/npm/marked@17.0.5/marked.min.js`
- marked-highlight 2.2.3: `https://cdn.jsdelivr.net/npm/marked-highlight@2.2.3/src/index.js`
- highlight.js 11.11.1: `https://cdn.jsdelivr.net/npm/highlight.js@11.11.1/build/highlight.min.js`
- highlight.js CSS theme (github-dark): `https://cdn.jsdelivr.net/npm/highlight.js@11.11.1/styles/github-dark.min.css`

**Markdown scope:** Apply only to AI reply bubbles. User messages render as plain text (no Markdown parsing — avoids XSS from user input).

**Security:** marked.js renders to HTML and is inserted via `innerHTML` — restrict to AI reply content only (server-controlled). User message text must use `textContent`, not `innerHTML`.

**Prose CSS class:** Scope Markdown-generated elements under `.prose` to prevent h1/h2/p/ul/code styles from leaking into chat chrome:
- `.prose h1, .prose h2, .prose h3`: font-size 1.1em–1.3em, weight 600, margin 8px 0 4px
- `.prose p`: margin 0 0 8px, line-height 1.5
- `.prose ul, .prose ol`: margin 0 0 8px, padding-left 20px
- `.prose code` (inline): background `#313145`, border-radius 4px, padding 1px 4px, font 13px monospace
- `.prose pre`: background `#1a1a2e`, border-radius 8px, padding 12px, overflow-x: auto, margin 0 0 8px
- `.prose a`: color accent `#7c6ff7`, underlined

## Registry Safety

Not applicable — no shadcn, no npm registry, no third-party component registry.

CDN libraries (marked.js, highlight.js) are read-only script includes with no registry vetting needed under this contract. Their integrity can optionally be verified with `integrity` + `crossorigin` SRI attributes on `<script>` tags — recommended but not required for v1.

| Registry | Blocks Used | Safety Gate |
|----------|-------------|-------------|
| shadcn official | none | not applicable — not a React project |
| npm registry | none | not applicable — no build toolchain |
| CDN (jsDelivr) | marked.js, marked-highlight, highlight.js | read-only script includes; SRI optional |
