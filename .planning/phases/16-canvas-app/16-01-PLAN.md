<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP → FastAPI | JWT cookie 検証済み — github_login は JWT から取得、ユーザー入力は使わない |
| FastAPI → PostgreSQL | psycopg パラメータ化クエリ — SQL インジェクション不可 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-16-01 | Information Disclosure | GET /api/canvas/gem | mitigate | JWT Depends(get_jwt_payload) を付けて認証済みユーザーのみ gem_id を取得可能にする |
| T-16-02 | Elevation of Privilege | Canvas 専用 Gem 自動登録 | accept | github_login='_canvas_system_' で登録 — JWT ユーザーは所有権チェックで排除される（gems.py WHERE github_login=%s）。Canvas Gem を一般ユーザーが削除・編集不可 |
| T-16-03 | Spoofing | deployed フィルタ | accept | deployed フィルタは読み取り専用クエリ。github_login による所有権チェックは既存の WHERE 句で継続 |
| T-16-04 | Tampering | GET /api/canvas/apps?deployed=true | mitigate | deployed パラメータは bool 型 FastAPI 検証 — 任意文字列の注入を防ぐ。パラメータ化クエリで SQL インジェクション不可 |
