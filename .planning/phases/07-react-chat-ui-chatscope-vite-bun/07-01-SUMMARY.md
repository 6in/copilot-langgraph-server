## Decisions Made

- **Vite proxy: no rewrite** — FastAPI routes are already prefixed with `/api/`, adding a rewrite rule would strip the prefix and break all routes
- **CORSMiddleware before `include_router`** — Starlette/FastAPI middleware must be registered before route inclusion to wrap them correctly (Pitfall 3 from 07-RESEARCH.md)
- **`os.path.isdir("frontend/dist")` guard** — prevents `StaticFiles` from raising `AssertionError` on FastAPI startup when the React build has not yet been run (Pitfall 5)
- **/react mount before / catch-all** — Starlette mount order is first-match; `/react` must appear before the `/` static files mount or it will never be reached
