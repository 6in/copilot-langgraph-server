    - `parse_since(v: str) -> datetime`: regex `^(\d+)([smhd])$` で相対形式を `datetime.now(timezone.utc) - timedelta(...)` に、それ以外は `datetime.fromisoformat(v.replace("Z","+00:00"))`

    - `is_span(obj) -> bool`: `isinstance(obj, dict)` かつ `{"trace_id","span_id","operation_name"}.issubset(obj.keys())`
    - `matches(span, args) -> bool`: 全フィルタを AND で判定。attributes 経由のフィルタは `span.get("attributes") or {}` から引く
    - `emit_ndjson` / `emit_pretty` / `emit_tsv`: それぞれ 1 span 1 行で出力
    - `emit_tree(spans, trace_id, out)`: 全 span を trace_id でグループ化 → parent_span_id → children の dict を作る → root span (parent_span_id が None または group 内にない span) から DFS で `├── ` `└── ` `│   ` `    ` の ASCII connector で描画
    - `main() -> int`: argparse で全フラグ、streaming mode (pretty/tsv/ndjson) は読みながら emit、tree mode は全部読み込んでから emit。`--max` に達したら break
    - `if __name__ == "__main__": sys.exit(main())`
