**POST /api/canvas/apps/upload (upload_app):**
- Request body: JSON `{"name": str, "html": str}` — Pydantic inline model `CanvasUploadRequest(BaseModel): name: str; html: str`
- INSERT INTO canvas_apps (github_login, name, html, source) VALUES (%s, %s, %s, 'upload') RETURNING app_id, thread_id, name, html, source, deployed, deployed_at, created_at
- thread_id は NULL（アップロードにはスレッドなし）
- Status 201、CanvasAppInfo を返す

**GET /api/canvas/apps (list_or_get_by_thread):**
- Query param: `thread_id: str | None = None`
- thread_id が指定された場合: SELECT ... FROM canvas_apps WHERE thread_id = %s AND github_login = %s ORDER BY created_at DESC LIMIT 1
- thread_id なし: SELECT ... FROM canvas_apps WHERE github_login = %s ORDER BY created_at DESC LIMIT 20
- 結果を `list[CanvasAppInfo]` で返す

**GET /api/canvas/apps/{app_id} (get_app):**
- SELECT ... FROM canvas_apps WHERE app_id = %s::uuid AND github_login = %s
- 見つからない場合: 404
- CanvasAppInfo を返す

**PATCH /api/canvas/apps/{app_id} (update_app):**
- Request body: JSON `{"html": str, "name": str | None}` — Pydantic inline model `CanvasUpdateRequest(BaseModel): html: str; name: str | None = None`
- UPDATE canvas_apps SET html = %s, (name = %s if provided) WHERE app_id = %s::uuid AND github_login = %s RETURNING ...
- 見つからない場合: 404
- CanvasAppInfo を返す

**POST /api/canvas/apps/{app_id}/deploy (deploy_app):**
- SELECT html FROM canvas_apps WHERE app_id = %s::uuid AND github_login = %s
- 見つからない場合: 404
- デプロイ処理:
  ```python
  deploy_dir = Path("./static/apps") / str(app_id)
  deploy_dir.mkdir(parents=True, exist_ok=True)
  (deploy_dir / "index.html").write_text(html, encoding="utf-8")
  ```
- UPDATE canvas_apps SET deployed = TRUE, deployed_at = now() WHERE app_id = %s::uuid
- CanvasDeployResponse(url=f"/apps/{app_id}/") を返す

**GET /api/canvas/apps/{app_id}/source (get_source):**
- SELECT thread_id FROM canvas_apps WHERE app_id = %s::uuid AND github_login = %s
- 見つからない場合: 404
- `{"thread_id": row["thread_id"]}` を返す（thread_id が NULL の場合もそのまま）

```python
def extract_html(text: str) -> str:
    """AI 出力からHTMLコードブロックを抽出する。```html で囲まれた部分を返す。"""
    m = re.search(r"```html\n(.*?)```", text, re.DOTALL)
    return m.group(1).strip() if m else text
```

**3. _get_gem_info ヘルパー関数を追加（モジュールレベル）:**

```python
async def _get_gem_info(thread_id: str, db_uri: str) -> tuple[str | None, str | None, str | None, str | None]:
    """thread_id から gem_id, gem_type, gem_name, system_prompt を取得する。"""
    try:
        async with await psycopg.AsyncConnection.connect(db_uri) as conn:
            async with conn.cursor() as cur:
                await cur.execute(
                    """SELECT g.gem_id, g.type, g.name, g.system_prompt
                       FROM threads t
                       LEFT JOIN gems g ON t.gem_id = g.gem_id
                       WHERE t.thread_id = %s""",
                    (thread_id,),
                )
                row = await cur.fetchone()
                if row and row[0] is not None:
                    return str(row[0]), row[1], row[2], row[3]
    except Exception:
        pass
    return None, None, None, None
```
