```python
"""Gem CRUD API routes — AI persona management (Phase 15).

Endpoints:
- POST   /api/gems              — Create a new Gem
- GET    /api/gems              — List user's Gems
- GET    /api/gems/{gem_id}     — Get a specific Gem
- PATCH  /api/gems/{gem_id}     — Update a Gem
- DELETE /api/gems/{gem_id}     — Delete a Gem
"""
import psycopg
from fastapi import APIRouter, Depends, HTTPException, Request
from psycopg.rows import dict_row

from app.api.models import GemCreate, GemInfo, GemUpdate
from app.api.routes.chat import get_jwt_payload

router = APIRouter(prefix="/api", tags=["gems"])
```

**POST /api/gems (create_gem):**
- Request body: `GemCreate(name, system_prompt, type)`
- `github_login = payload.get("github_login", "unknown")`
- INSERT INTO gems (github_login, name, system_prompt, type) VALUES (%s, %s, %s, %s) RETURNING gem_id, name, system_prompt, type, created_at, updated_at
- datetime を `.isoformat()` で文字列化して `GemInfo` で返す
- Status 201

**GET /api/gems (list_gems):**
- `response_model=list[GemInfo]`
- SELECT gem_id, name, system_prompt, type, created_at, updated_at FROM gems WHERE github_login = %s ORDER BY created_at DESC
- `row_factory=dict_row` を使い、datetime フィールドを `.isoformat()` で変換

**GET /api/gems/{gem_id} (get_gem):**
- SELECT ... FROM gems WHERE gem_id = %s::uuid AND github_login = %s
- 見つからない場合: `raise HTTPException(status_code=404, detail="Gem not found")`
- `%s::uuid` キャストで UUID 文字列を安全にバインド

**PATCH /api/gems/{gem_id} (update_gem):**
- Request body: `GemUpdate(name?, system_prompt?, type?)`
- `body.model_dump(exclude_unset=True)` で更新フィールドのみ取得
- 空なら 422 を返す
- UPDATE gems SET {field}=%s, ..., updated_at=now() WHERE gem_id = %s::uuid AND github_login = %s
- SET 句を動的に構築（`", ".join(f"{k} = %s" for k in fields)` + values リスト）
- RETURNING で更新後の行を返す
- 見つからない場合: 404

**DELETE /api/gems/{gem_id} (delete_gem):**
- DELETE FROM gems WHERE gem_id = %s::uuid AND github_login = %s
- rowcount == 0 なら 404
- Status 204 (`status_code=204`, return None)

**所有権チェック:** すべてのエンドポイントで WHERE github_login = %s を使い、他ユーザーの Gem へのアクセスを防ぐ。404 を返すことで Gem の存在自体を漏洩させない。
