```python
def bind_tools(
    self,
    tools: Sequence[Any],
    *,
    tool_choice: str | None = None,
    **kwargs: Any,
) -> "BoundChatCopilot":
    """Bind tools to this model via prompt engineering (D-01).
    
    Returns a BoundChatCopilot that injects tool schemas into the system
    prompt and parses JSON responses into AIMessage(tool_calls=[...]).
    """
    from langchain_core.tools import BaseTool as BT
    base_tools = [t for t in tools if isinstance(t, BT)]
    return BoundChatCopilot(
        tools=base_tools,
        model=self.model,
        github_token=self.github_token,
        auth_manager=self.auth_manager,
    )
```

**3. copilot.py の末尾（ChatCopilot クラスの後）に BoundChatCopilot クラスを追加:**

TOOL_SYSTEM_PROMPT_TEMPLATE 定数:
```
You have access to the following tools:
{tool_schemas}

To call a tool, respond ONLY with valid JSON (no markdown, no explanation):
{{"tool": "<tool_name>", "args": {{...}}}}

If no tool is needed, respond normally in plain text.
```

BoundChatCopilot(ChatCopilot) クラス:
- `_bound_tools: list = PrivateAttr(default_factory=list)` (PrivateAttr で Pydantic スキーマ汚染回避)
- `__init__(self, tools: list, **kwargs)`: super().__init__(**kwargs) を呼び、object.__setattr__(self, '_bound_tools', tools) で設定
- `_agenerate(self, messages, stop=None, run_manager=None, **kwargs)`:
  - tool_schemas = json.dumps([{"name": t.name, "description": t.description, "parameters": t.get_input_jsonschema()} for t in self._bound_tools], ensure_ascii=False, indent=2)
  - SystemMessage(content=TOOL_SYSTEM_PROMPT_TEMPLATE.format(tool_schemas=tool_schemas)) を messages の先頭に注入
  - result = await super()._agenerate(augmented_messages, ...) を呼ぶ
  - content = result.generations[0].message.content
  - _try_parse_tool_call(content) を呼び、ToolCall が得られれば AIMessage(content="", tool_calls=[tool_call]) で ChatResult を返す
  - 得られなければ result をそのまま返す

- `_try_parse_tool_call(self, content: str) -> ToolCall | None` ヘルパーメソッド:
  - まず content.strip() を json.loads() で試す
  - JSONDecodeError の場合、markdown コードブロック除去を試みる: `re.sub(r'^```(?:json)?\s*\n?', '', content.strip())` + 末尾の ``` を除去してから再度 json.loads()
  - パース成功かつ dict に "tool" キーがあれば ToolCall(name=parsed["tool"], args=parsed.get("args", {}), id=str(uuid.uuid4())[:8]) を返す
  - それ以外は None を返す
