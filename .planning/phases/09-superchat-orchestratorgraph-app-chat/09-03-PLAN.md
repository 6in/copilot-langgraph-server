# Plan 09-03: Frontend mode toggle in React UI

**Phase:** 09 - SuperChat OrchestratorGraph App Integration
**Plan:** 03 of 04
**Goal:** Add a mode toggle (Simple / Super) to the React chat UI and thread the selected mode through to the POST /api/chat request body.

## Context

Per D-08, the React UI needs a mode toggle so users can switch between `simple` (existing LangGraph chat) and `super` (OrchestratorGraph multi-agent routing). The toggle state is local React state (not persisted to thread). The `useChat` hook passes `mode` in the POST body, and the backend (Plan 09-02) routes accordingly. Default is `simple` so existing behavior is unchanged.

## Canonical References

- `frontend/src/types.ts` -- ChatRequest interface
- `frontend/src/api/client.ts` -- postChat function
- `frontend/src/hooks/useChat.ts` -- UseChatOptions, sendMessage
- `frontend/src/components/MessageArea.tsx` -- input bar where toggle goes
- `frontend/src/components/ChatApp.tsx` -- useChat call site, state management

## Prerequisites

Plan 09-02 must be complete (backend must accept `mode` field in ChatRequest).
