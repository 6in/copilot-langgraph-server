### Task 2: Manual UAT -- live mode switching

**Files:** (no files created)
**Action:** human verification

This is a manual UAT checklist. Start the full stack with `docker compose up` and verify in the browser.

**Pre-condition:** `docker compose up` starts without errors. Frontend accessible at `http://localhost:5173/app`.

**UAT Steps:**

1. **Login:** Complete Device Flow auth. Verify you reach the chat interface.

2. **Simple mode (default):**
   - Verify the mode toggle shows "Simple" and "Super" buttons in the input bar
   - Verify "Simple" button is highlighted (blue background) by default
   - Type "Hello" and send
   - Verify you get a response (this uses the existing LangGraph handler)
   - Verify the response appears in the message list

3. **Super mode:**
   - Click the "Super" toggle button
   - Verify "Super" button becomes highlighted, "Simple" becomes unhighlighted
   - Type "Review this Python code: print('hello')" and send
   - Verify you get a response from the code-reviewer agent (should contain code review feedback)
   - Verify the response appears in the message list

4. **Mode persistence:**
   - Switch back to "Simple" mode
   - Send another message
   - Verify it uses the simple LangGraph handler (normal chat response)

5. **Thread switching:**
   - Create a new thread
   - Verify the mode toggle resets to "Simple" (or stays at current -- per D-08, mode is local state not tied to thread)

6. **Error resilience:**
   - If `agents/` directory were empty/missing, super mode should return an error message (not crash the UI)

**Verification:** Human confirms all steps pass, or reports specific failures for debugging.

## Notes

- Super-mode responses will NOT appear in thread history on page refresh (no checkpointer for orchestrator). This is expected and deferred.
- The first `mode='super'` request may be slower as `SubAgentRegistry` reads AGENT.md files and ChatCopilot instances start Copilot SDK subprocesses. Subsequent requests in the same worker process are not cached (per-job construction), so each request has similar latency.
- If the smoke test fails on Task 1 step 4 (SubAgentRegistry), verify that `agents/code-reviewer/AGENT.md` has valid YAML frontmatter with `name`, `description`, and `model` fields.
