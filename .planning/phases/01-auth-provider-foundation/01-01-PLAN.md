3. Create `app/auth/manager.py` implementing `CopilotAuthManager` exactly as specified in the research document's Pattern 1 section. Key implementation details:

   - Class: `CopilotAuthManager`
   - Constructor: `__init__(self, token_path: str = "~/.copilot_sdk/token.enc")`
   - Constants at module level:
     - `GITHUB_DEVICE_CODE_URL = "https://github.com/login/device/code"`
     - `GITHUB_TOKEN_URL = "https://github.com/login/oauth/access_token"`
     - `CLIENT_ID = "Iv1.b507a08c87ecfe98"`
     - `DEVICE_CODE_EXPIRY_SECS = 900`
   - `_get_or_create_fernet_key()` -> bytes: checks `COPILOT_TOKEN_ENC_KEY` env var first, then reads/creates key file at `self.token_path.parent / ".enc_key"` with `chmod(0o600)`
   - `save_token(github_token: str)` -> None: JSON-encodes `{"github_token": token, "saved_at": iso_timestamp}`, Fernet-encrypts, writes to `self.token_path` with `chmod(0o600)`
   - `load_token()` -> `str | None`: reads and decrypts token file, returns None on any error or missing file
   - `device_login()` -> str (async): POST to GITHUB_DEVICE_CODE_URL with `client_id` and `scope=read:user`, print verification_uri and user_code, poll GITHUB_TOKEN_URL with `asyncio.sleep(interval)` AT THE START of each iteration (not after), handle `slow_down` by incrementing interval by 5, handle `authorization_pending` by continuing, raise RuntimeError on unknown errors or timeout
   - `get_token()` -> str (async): tries load_token() first, falls back to device_login()

   CRITICAL: The polling loop MUST sleep BEFORE the POST request (at the top of the while loop), not after. This prevents the slow_down bug documented in Pitfall 7.

4. Run `uv run pytest tests/test_auth.py -x -v` — all tests must PASS (GREEN).
