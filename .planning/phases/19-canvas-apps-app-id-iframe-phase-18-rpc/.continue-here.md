## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Vite プロキシと絶対パス | Shell HTML 内の `/js/...` や `/api/...` 絶対パスはブラウザが Vite の origin root で解決するため、`VITE_APP_BASE` プレフィックス付きのパスでないと Vite プロキシを通らない | advisory | `VITE_APP_BASE` を api コンテナにも渡し、ホスト側 HTML と JS の URL 構築時に使う |
| StaticFiles と動的ルートの競合 | `app.mount("/apps", StaticFiles(...))` はプレフィックスマッチのため、trailing slash あり URL（`/apps/uuid/`）を動的ルートより先に捕捉する | advisory | 動的ルートに trailing slash バリアント（`@router.get("/apps/{app_id}/")`）を追加する |
