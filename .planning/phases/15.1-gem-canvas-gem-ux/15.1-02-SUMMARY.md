# Phase 15.1 Plan 02: フロントエンド description / knowledge フィールド対応 Summary

**One-liner:** `GemInfo`・`GemCreate` 型に `description`/`knowledge` を追加し、GemsScreen の編集・作成フォームと通常表示カードを対応させた。

## What Was Done

### Task 1: types.ts
- `GemInfo` に `description: string` と `knowledge: string` を追加
- `GemCreate` に `description: string` と `knowledge: string` を追加

### Task 2: GemsScreen.tsx
- `editDescription` / `editKnowledge` state を追加
- `handleEdit` で gem の description / knowledge を初期化
- `handleCancelEdit` で description / knowledge をリセット
- `handleSave` の `updateGem` 呼び出しに description / knowledge を含める
- `createDescription` / `createKnowledge` state を追加
- `handleShowCreateForm` / `handleCancelCreate` でリセット処理を追加
- `handleCreate` の `createGem` 呼び出しに description / knowledge を含める（成功後もリセット）
- カード通常表示を `gem.system_prompt` → `gem.description` に切り替え（空の場合は「説明なし」イタリック表示）
- インライン編集フォームに Description input（maxLength=200）と Knowledge textarea（rows=3, maxLength=8000）を追加（System Prompt の直後）
- 新規作成フォームに同フィールドを追加（System Prompt の直後、Type セレクトの前）
