# Phase 15.1: Gem UX 強化 — Gems をアプリとして MenuScreen に統合 - Context

**Gathered:** 2026-04-05
**Status:** Ready for planning

<domain>
## Phase Boundary

Gem 機能を「アプリ」として再設計する。MenuScreen に「Gems」という1枚のアプリカードを固定追加する。クリックすると GemsScreen（ハブ画面）が開き、Gem の一覧管理（CRUD）と Gem 選択によるチャット起動ができる。既存 ChatApp / SuperChatApp から GemSelector チップストリップを撤去する。

### このフェーズで実装すること

1. **MenuScreen に「Gems」アプリカードを追加** — 既存アプリカード群と同列に「Gems」1枚を固定追加。個別 Gem のカードは並べない
2. **GemsScreen 新規作成** — Gems カードをクリックすると表示されるハブ画面。Gem CRUD（作成・編集・削除）+ Gem 選択でチャット起動
3. **GemChatApp 新規作成** — GemsScreen で Gem を選択したときに起動するチャットコンポーネント。ヘッダーに Gem 名を表示
4. **GemSelector の撤去** — ChatApp・SuperChatApp から GemSelector コンポーネントと関連 props を削除

### スコープ外（保留）

- Canvas 関連（デプロイフロー改善、Canvas App 一覧管理）— 別フェーズ
- Canvas Gem の MenuScreen 特別対応（Phase 15.1 では Gem タイプに関わらず同一扱い）

</domain>

<decisions>
## Implementation Decisions

### MenuScreen カード追加

- **D-01:** 既存 Apps グリッドに「Gems」カードを1枚固定追加する（個別 Gem のカードは並べない）
- **D-02:** Gems カードは FeatureCard コンポーネントを流用（icon `💎`、title "Gems"、description は実装者判断）
- **D-03:** Gems カードをクリックすると `showGemsScreen: boolean` ステート（App.tsx）が true になり GemsScreen を表示する

### App.tsx ナビゲーション

- **D-04:** App.tsx に `showGemsScreen: boolean` と `activeGem: GemInfo | null` の2つのステートを追加する
- **D-05:** `showGemsScreen = true` → GemsScreen を表示（activeApp / activeGem は null）
- **D-06:** GemsScreen で Gem を選択 → `activeGem` をセット、`showGemsScreen = false` → GemChatApp を表示
- **D-07:** GemChatApp のヘッダーまたは Back ボタンで `activeGem = null` に戻す → GemsScreen に戻る

### GemsScreen（ハブ画面）

- **D-08:** `GemsScreen` コンポーネントを新規作成する（`frontend/src/components/GemsScreen.tsx`）
- **D-09:** Gem 一覧（カードまたはリスト）+ 作成フォーム + 編集インライン + 削除確認を1画面に収める
- **D-10:** 各 Gem に「Chat」ボタン → `onSelectGem(gem)` コールバックで GemChatApp を起動する
- **D-11:** `useGems` フックに `updateGem(gemId, data)` を追加する（バックエンドの PATCH /api/gems/{gem_id} 実装済み）
- **D-12:** Back ボタンで MenuScreen に戻る（`onBack` コールバック）

### GemChatApp

- **D-13:** `GemChatApp` コンポーネントを新規作成する（`frontend/src/components/GemChatApp.tsx`）
- **D-14:** ChatApp と同構造（ThreadSidebar + MessageArea）だが、ヘッダーバーに Gem 名を表示する
- **D-15:** `useThreads('gem-${gem.gem_id}')` でスレッドを Gem 単位に分離する
- **D-16:** `useChat` に `gemId: gem.gem_id` を渡す（既存の gem_id 送信ロジックを活用）
- **D-17:** GemChatApp は CanvasPane・GemSelector を持たない（シンプルなチャットのみ）

### GemSelector 撤去

- **D-18:** `ChatApp.tsx` から `GemSelector` import・`selectedGemId` state・`onSelectGem` props を削除する
- **D-19:** `SuperChatApp.tsx` から同様に削除する
- **D-20:** `MessageArea.tsx` から `selectedGemId`・`onSelectGem` props を削除し、GemSelector レンダリングを除去する
- **D-21:** `useChat` の `gemId` オプションは残す（GemChatApp が引き続き使用するため）

### Claude's Discretion

- GemChatApp のヘッダーバーのデザイン詳細（高さ・背景色等）— ChatApp との一貫性を優先
- GemsScreen のレイアウト詳細（カードリスト vs テーブル）— シンプルさを優先
- Gems カードの icon（`💎` 固定で OK）

</decisions>

<code_context>
## Existing Code Insights

### Reusable Assets
- `FeatureCard` (MenuScreen.tsx 内) — Gem カードにそのまま流用可能。icon, title, description, onClick を受け取る
- `useGems` (hooks/useGems.ts) — Gem 一覧・作成・削除を提供。`updateGem` を追加するだけで管理ページに使える
- `useChat` (hooks/useChat.ts) — `gemId` オプションが既に実装済み。GemChatApp で使用可能
- `ChatApp.tsx` — GemChatApp の構造的ベース（ThreadSidebar + drag handle + MessageArea のパターン）

### Established Patterns
- App.tsx のナビゲーション: `activeApp: AppDefinition | null` → null で MenuScreen、非 null でアプリ表示。同パターンで `activeGem` を追加
- `useThreads('chat')` / `useThreads(appId)` — モード文字列でスレッドを分離。`useThreads('gem-{gem_id}')` で Gem 別スレッド分離が可能
- `useGems` フックは楽観的更新（setGems で即時反映）— updateGem も同パターンで実装

### Integration Points
- `App.tsx` — `showGemsScreen` / `activeGem` ステート追加、MenuScreen / GemsScreen / GemChatApp の条件レンダリング
- `MenuScreen.tsx` — `onNavigate` に加えて `onOpenGems()` コールバックを追加（Gems カードクリック時）
- `MessageArea.tsx` — GemSelector props（`selectedGemId`, `onSelectGem`）を削除、ルートラッパー div も整理

</code_context>
