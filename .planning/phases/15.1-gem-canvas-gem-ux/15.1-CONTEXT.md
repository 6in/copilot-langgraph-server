# Phase 15.1: Gem UX 強化 — Gems をアプリとして MenuScreen に統合 - Context

**Gathered:** 2026-04-05
**Status:** Ready for planning

<domain>
## Phase Boundary

Gem 機能を「アプリ」として再設計する。ユーザーは MenuScreen の Gems セクションから Gem を選択してチャットを開始できる。Gem CRUD は専用管理ページで行う。既存 ChatApp / SuperChatApp から GemSelector チップストリップを撤去する。

### このフェーズで実装すること

1. **MenuScreen の Gems セクション追加** — Apps グリッドの下に独立した Gems セクションを追加。Gem カード一覧 + 管理ページへのリンク
2. **GemChatApp 新規作成** — Gem 選択時に起動する専用チャットコンポーネント。ヘッダーに Gem 名を表示
3. **Gems 管理ページ新規作成** — Gem CRUD（作成・編集・削除）を行う専用ページ。MenuScreen Gems セクションからリンク
4. **GemSelector の撤去** — ChatApp・SuperChatApp から GemSelector コンポーネントと関連 props を削除

### スコープ外（保留）

- Canvas 関連（デプロイフロー改善、Canvas App 一覧管理）— 別フェーズ
- Canvas Gem の MenuScreen 特別対応（Phase 15.1 では Gem タイプに関わらず同一扱い）

</domain>

<decisions>
## Implementation Decisions

### MenuScreen レイアウト

- **D-01:** Apps グリッド（既存）の下に独立した「Gems」セクションを追加する
- **D-02:** Gems セクションには Gem カード一覧（API から動的取得）+ 「Manage Gems」リンクを配置する
- **D-03:** Gem カードのデザインは既存 FeatureCard コンポーネントを流用する（icon は `💎` または Gem 名先頭文字など）

### App.tsx ナビゲーション

- **D-04:** App.tsx に `activeGem: GemInfo | null` ステートを追加する
- **D-05:** Gem 選択時は `activeGem` をセット → GemChatApp をレンダリングする（activeApp のパターンを踏襲）
- **D-06:** 「Manage Gems」選択時は `showGemsManager: boolean` ステートで GemsManagerPage を表示する

### GemChatApp

- **D-07:** `GemChatApp` コンポーネントを新規作成する（`frontend/src/components/GemChatApp.tsx`）
- **D-08:** ChatApp と同構造（ThreadSidebar + MessageArea）だが、ヘッダーバーに Gem 名を表示する
- **D-09:** `useThreads('gem-{gem_id}')` でスレッドを Gem 単位に分離する
- **D-10:** `useChat` に `gemId: gem.gem_id` を渡す（既存の gem_id 送信ロジックを活用）
- **D-11:** GemChatApp は CanvasPane・GemSelector を持たない（シンプルなチャットのみ）

### Gems 管理ページ

- **D-12:** `GemsManagerPage` コンポーネントを新規作成する（`frontend/src/components/GemsManagerPage.tsx`）
- **D-13:** Gem 一覧（テーブルまたはカードリスト）+ 作成フォーム + 編集インライン + 削除確認を提供する
- **D-14:** `useGems` フックに `updateGem(gemId, data)` を追加する（バックエンドの PATCH /api/gems/{gem_id} が既に実装済み）
- **D-15:** 管理ページから Back ボタンで MenuScreen に戻る

### GemSelector 撤去

- **D-16:** `ChatApp.tsx` から `GemSelector` import・`selectedGemId` state・`onSelectGem` props を削除する
- **D-17:** `SuperChatApp.tsx` から同様に削除する
- **D-18:** `MessageArea.tsx` から `selectedGemId`・`onSelectGem` props を削除し、GemSelector レンダリングを除去する
- **D-19:** `useChat` の `gemId` オプションは残す（GemChatApp が引き続き使用するため）

### Claude's Discretion

- GemChatApp のヘッダーバーのデザイン詳細（高さ・背景色等）— ChatApp との一貫性を優先
- GemsManagerPage の具体的レイアウト（テーブル vs カードリスト）— シンプルさを優先
- Gem カードの icon 表示方法（`💎` 固定 vs Gem 名先頭文字バッジ）

</decisions>

<code_context>
## Existing Code Insights

### Reusable Assets
- `FeatureCard` (MenuScreen.tsx 内) — Gem カードにそのまま流用可能。icon, title, description, onClick を受け取る
- `useGems` (hooks/useGems.ts) — Gem 一覧・作成・削除を提供。`updateGem` を追加するだけで管理ページに使える
- `useChat` (hooks/useChat.ts) — `gemId` オプションが既に実装済み。GemChatApp で使用可能
- `ChatApp.tsx` — GemChatApp の構造的ベース（ThreadSidebar + drag handle + MessageArea のパターン）

### Established Patterns
- App.tsx のナビゲーション: `activeApp: AppDefinition | null` → null で MenuScreen、非 null でアプリ表示。同パターンで `activeGem` を追加
- `useThreads('chat')` / `useThreads(appId)` — モード文字列でスレッドを分離。`useThreads('gem-{gem_id}')` で Gem 別スレッド分離が可能
- `useGems` フックは楽観的更新（setGems で即時反映）— updateGem も同パターンで実装

### Integration Points
- `App.tsx` — activeGem / showGemsManager ステート追加、GemChatApp / GemsManagerPage の条件レンダリング
- `MenuScreen.tsx` — `onNavigate` に加えて `onSelectGem(gem: GemInfo)` と `onManageGems()` コールバックを追加
- `MessageArea.tsx` — GemSelector props（`selectedGemId`, `onSelectGem`）を削除、ルートラッパー div も整理

</code_context>

<specifics>
## Specific Ideas

- GemChatApp ヘッダーに表示するのは Gem 名のみ（システムプロンプトは折り畳み・非表示でよい）
- Gems セクションの「Manage Gems」はリンクボタンまたはテキストリンクで OK（派手な UI 不要）
- GemSelector コンポーネントファイル自体は削除せず、import されなくなった時点で自然消滅させる方針でも可

</specifics>
