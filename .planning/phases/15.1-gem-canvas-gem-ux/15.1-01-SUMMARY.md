**One-liner:** `gems` テーブルに `description`/`knowledge` カラムを追加し、API モデル・routes・LangGraph ハンドラーで knowledge を system_prompt に結合する実装。

## 主な変更内容

### app/api/main.py
`gems_github_login_idx` インデックス作成の直後に `ADD COLUMN IF NOT EXISTS` を2行追加。起動のたびに実行されても冪等。

### app/api/models.py
- `GemCreate`: `description: str = ""` と `knowledge: str = ""` を追加（デフォルト空文字）
- `GemUpdate`: `description: str | None = None` と `knowledge: str | None = None` を追加
- `GemInfo`: `description: str` と `knowledge: str` を必須フィールドとして追加

### app/api/routes/gems.py
- `_row_to_gem`: `row.get("description", "")` / `row.get("knowledge", "")` で安全に取得
- `create_gem`: INSERT に `description`/`knowledge` カラムと値を追加
- `list_gems`・`get_gem`: SELECT に `description`/`knowledge` を追加
- `update_gem`: `allowed_columns` に `"description"`, `"knowledge"` を追加、RETURNING 句も更新

### app/jobs/handlers/langgraph_handler.py
- `_get_gem_info`: `g.knowledge` を SELECT に追加、返り値を `(gem_id, gem_type, gem_name, system_prompt, knowledge)` の 5 要素タプルに変更
- `handle`: アンパックを 5 変数に変更、knowledge 結合ロジックを追加:
  - `system_prompt` あり + `knowledge` あり → `system_prompt + "\n\n## 知識\n" + knowledge`
  - `system_prompt` なし + `knowledge` あり → `"## 知識\n" + knowledge`
