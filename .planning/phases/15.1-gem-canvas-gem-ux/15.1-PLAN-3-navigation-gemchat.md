`GemChatApp` コンポーネントを新規作成し、`App.tsx` のナビゲーションを4画面対応に拡張し、`MenuScreen` に Gems 固定カードを追加する。すべてのパーツをつないで `MenuScreen → GemsScreen → GemChatApp` のフローを完成させる。最後にブラウザでの手動 UI 確認チェックポイントを設ける。

### App.tsx ナビゲーション
```typescript
type Screen = 'menu' | 'superchat' | 'gems' | 'gemchat';
const [currentScreen, setCurrentScreen] = useState<Screen>('menu');
const [activeApp, setActiveApp] = useState<AppDefinition | null>(null);
const [activeGem, setActiveGem] = useState<GemInfo | null>(null);

const handleOpenGems = () => { setCurrentScreen('gems'); };
const handleSelectGem = (gem: GemInfo) => { setActiveGem(gem); setCurrentScreen('gemchat'); };
const handleBackFromGemChat = () => { setActiveGem(null); setCurrentScreen('gems'); };
const handleBackFromGems = () => { setCurrentScreen('menu'); };
```

### MenuScreen Gems カード配置
- **CRITICAL（Pitfall 5）:** Gems カードは `apps.map()` の外側に配置する。`apps.length > 0` 条件ブランチの中に入れてはいけない
- ローディング中のスケルトンカードには含めない
- グリッドは現在ローディング中 / 空状態 / apps.length > 0 で分岐しているが、Gems カードは常に表示するために独立したグリッドとして描画するか、既存グリッドの外に配置する

推奨実装: 既存のグリッド分岐を維持しつつ、Gems カードを先頭に固定した独立したグリッドセクションとして追加する:
```tsx

<div style={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fill, minmax(180px, 1fr))', gap: '1rem', width: '100%', maxWidth: '600px', marginBottom: '1rem' }}>
  <FeatureCard
    icon="💎"
    title="Gems"
    description="AI ペルソナを管理してチャットを起動する"
    cardBg={cardBg}
    cardBorder={cardBorder}

```

### App.tsx での GemChatApp の表示
`currentScreen === 'gemchat'` のとき:
- グローバル `Header` を表示する（`onBackToMenu` は activeApp がある場合のみ渡す。Gems から起動した場合はヘッダーの Back ボタンを使わず、GemChatApp 内部の Back ボタンを使う）

## Threat Model

**In scope:** フロントエンドのナビゲーション変更。GemChatApp のスレッド分離。

**Threats identified:**

1. **スレッド分離の欠如:** `useThreads('gem-${gem.gem_id}')` が正しく動作しない場合、異なる Gem のスレッドが混在する。**緩和策:** D-15 通りに `gem_id` を appId として渡す。バックエンドの GET /api/threads?app_id= フィルタは既実装済み。ブラウザ確認（Task 3 手順 5〜7）で動作確認する。

2. **activeGem が null のまま GemChatApp が表示される:** `currentScreen === 'gemchat'` かつ `activeGem === null` になるコードパスが残ると null 参照エラー。**緩和策:** レンダリング条件を `currentScreen === 'gemchat' && activeGem` とする（`activeGem!` のノンヌルアサーションより安全）。

3. **GemChatApp の Back ボタンが MenuScreen まで戻ってしまう:** Header の `onBackToMenu` を渡した場合に発生。**緩和策:** `currentScreen === 'gemchat'` のとき Header に `onBackToMenu` を渡さず、GemChatApp 内の `onBack` のみで GemsScreen に戻る（Pitfall 4 対策、D-07）。

**Out of scope:** バックエンドの認証・認可（変更なし）。XSS（GemChatApp のメッセージは既存の MarkdownMessage コンポーネントを通じて表示される）。
</threat_model>
