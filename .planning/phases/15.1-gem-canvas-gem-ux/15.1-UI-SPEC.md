## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | アイコンと文字の gap、チップ内の inline gap |
| sm | 8px | チップ間 gap、コンパクト要素間スペース |
| md | 16px | フォームフィールド間、ヘッダー内 gap |
| lg | 24px | カードの padding（1.5rem = 24px）、セクション padding |
| xl | 32px | ページ垂直 padding の基準 |
| 2xl | 48px | MenuScreen の画面 top padding（3rem = 48px） |
| 3xl | 64px | 使用しない（画面構造は flex で制御） |

Exceptions:
- ヘッダーバー高さ: 48px（Header.tsx 既存値、GemChatApp ヘッダーも同値で統一）
- チップ高さ: 28px（GemSelector.tsx 既存値、GemsScreen のアクションボタンに流用可）
- カードボーダーラジアス: 12px（FeatureCard 既存値）
- フォーム入力ボーダーラジアス: 6px（GemSelector.tsx 既存値）

Source: MenuScreen.tsx（padding: '3rem 2rem'）、Header.tsx（height: '48px'）、GemSelector.tsx（chip height: '28px', input borderRadius: '6px'）

## Component Inventory

このフェーズで追加・変更するコンポーネントと、その視覚的仕様。

### 1. MenuScreen に Gems 固定カードを追加

- **コンポーネント:** `FeatureCard`（既存、再利用）
- **配置:** `apps.map()` の外側、グリッドの先頭に固定配置（apps ロード中も常に表示）
- **Props:** `icon="💎"`, `title="Gems"`, `description="AI ペルソナを管理してチャットを起動する"`
- **ホバー:** `box-shadow: '0 4px 16px rgba(0,0,0,0.18)'`, `transform: 'translateY(-2px)'`（既存 FeatureCard 動作そのまま）
- **フォーカス:** `button:focus-visible { outline: 2px solid #7c6ff7; outline-offset: 2px; }`

### 2. GemsScreen（新規）

レイアウト: 縦方向スクロール可能な管理ハブ画面。MenuScreen と同一の画面背景（`screenBg`）を使用。

#### 2a. 画面構造

```
[Back ボタン] [見出し "Gems"]
[Gem 一覧グリッド（カードリスト）]
[新規作成フォーム / + ボタン]
```

- 外側コンテナ: `flex: 1, display: 'flex', flexDirection: 'column', alignItems: 'center', padding: '48px 32px', background: screenBg, overflowY: 'auto'`
- コンテンツ最大幅: `maxWidth: '640px', width: '100%'`

#### 2b. Back ボタン

- `padding: '0.25rem 0.75rem'`, `borderRadius: '4px'`, `border: '1px solid #555'`（Header の Back ボタンスタイルと統一）
- ラベル: `← Back`
- 位置: 見出しの左上（flex row の先頭）

#### 2c. Gem 管理カード（一覧）

- カードの外形: `FeatureCard` のスタイルを踏襲（`cardBg`, `cardBorder`, `borderRadius: '12px'`, `padding: '24px'`）
- カード内表示: Gem 名（`fontSize: '1rem', fontWeight: 600`）+ system_prompt の冒頭 50 文字（`fontSize: '0.875rem', color: subtitleColor`）
- アクションボタン群（カード右下または下部 flex row）:
  - **チャット開始** ボタン（primary）: `background: '#7c6ff7', color: '#fff', borderRadius: '6px', padding: '4px 12px', fontSize: '0.875rem', fontWeight: 600`
  - **Edit** ボタン（secondary）: `background: 'transparent', border: '1px solid #d1dbe3', borderRadius: '6px', padding: '4px 12px', fontSize: '0.875rem'`
  - **Delete** ボタン（destructive）: `background: 'none', border: 'none', color: '#e05252', fontSize: '0.875rem', cursor: 'pointer'`

#### 2d. 削除確認（インライン）

- 削除ボタンクリック後、カード内に `"削除しますか？"` テキスト + `Yes`（color: `#e05252`）/ `No` ボタンをインライン表示
- モーダルは使用しない（GemSelector.tsx の inline confirm パターンを踏襲）

#### 2e. 編集フォーム（インライン展開）

- Edit ボタンクリックでカード内に展開するインラインフォーム
- フィールド: Name（maxLength: 80）、System Prompt（maxLength: 4000）
- 入力スタイル: `border: '1px solid #d1dbe3', borderRadius: '6px', padding: '8px 12px', fontSize: '0.875rem'`
- アクション: **変更を保存** ボタン（primary、`#7c6ff7` 背景）/ **編集をやめる** ボタン（secondary）

#### 2f. 新規作成

- `+` ボタン（chipUnselected スタイル）または画面下部の「New Gem」ボタンで展開
- フォームフィールド: Name + System Prompt + Type（default / canvas ラジオまたは select）
- Type フィールドは最小限の UI（GemSelector.tsx の `formType` パターン踏襲）

#### 2g. 空状態

- テキスト: `"Gems がありません"` (fontWeight: 600) + `"+ ボタンをクリックして最初の Gem を作成してください"` (subtitleColor)

#### 2h. エラー状態

- `role="alert"`, `background: 'rgba(224,82,82,0.1)'`, `border: '1px solid #e05252'`, `borderRadius: '8px'`, `padding: '12px 16px'`, `color: '#e05252'`

### 3. GemChatApp（新規）

ChatApp.tsx を構造的ベースとして使用。CanvasPane / GemSelector を除いたシンプルな構成。

#### 3a. 画面構造

```
[Gem ヘッダーバー（Gem 名 + Back ボタン）]
[MainContainer]
  [ThreadSidebar] | [drag handle] | [MessageArea]
```

ヘッダーバーは ChatApp の Header コンポーネントとは独立した内部実装とする（D-07 / RESEARCH.md Open Question 2 の解決策）。

#### 3b. Gem ヘッダーバー

```
display: 'flex', alignItems: 'center', gap: '12px',
padding: '8px 16px',
height: '48px',
borderBottom: '1px solid #d1dbe3',
background: cardBg（テーマ対応）,
flexShrink: 0
```

- Back ボタン: `← Back`、Header.tsx の onBackToMenu ボタンと同一スタイル
- Gem 名: `💎 {gem.name}`、`fontSize: '1rem', fontWeight: 600, color: textColor`
- Gem ヘッダーバーは `Header` コンポーネント（最上部のグローバルヘッダー）の下に配置

#### 3c. ThreadSidebar・MessageArea

ChatApp.tsx の既存実装をそのまま使用。独自スタイルは追加しない。

## Interaction Contract

### ナビゲーションフロー

```
MenuScreen
  └─ [Gems カードクリック] → GemsScreen
        └─ [チャット開始 ボタン] → GemChatApp
              └─ [← Back] → GemsScreen
        └─ [← Back] → MenuScreen
```

### 状態遷移

| 状態 | トリガー | 結果 |
|------|---------|------|
| `currentScreen = 'menu'` | 初期状態 | MenuScreen 表示 |
| `currentScreen = 'gems'` | Gems カードクリック | GemsScreen 表示 |
| `currentScreen = 'gemchat'` | GemsScreen の チャット開始 ボタン | GemChatApp 表示、`activeGem` セット |
| `currentScreen = 'gems'` | GemChatApp の Back ボタン | GemsScreen に戻る、`activeGem = null` |
| `currentScreen = 'menu'` | GemsScreen の Back ボタン | MenuScreen に戻る |

### フォーカス管理

- すべてのボタンは `button:focus-visible { outline: 2px solid #7c6ff7; outline-offset: 2px; }` を持つ
- GemsScreen のフォーム展開後は最初の入力フィールドにフォーカスを移動する

### ローディング状態

- GemsScreen: Gem 一覧フェッチ中は SkeletonCard 3枚（MenuScreen.tsx の `SkeletonCard` パターンを GemsScreen に再実装）
- 作成・編集・削除のサブミット中: ボタンを `disabled` に設定、テキストを `"Saving..."` / `"Deleting..."` に変更
