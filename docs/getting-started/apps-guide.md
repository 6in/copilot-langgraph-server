# Apps Guide — どのアプリをいつ使うか

このシステムには 5 つのアプリがある。「自分の目的にどれが合うか」をフローと表で把握できるようにまとめた。

> **入口:** ログイン後の MenuScreen から起動できる。最近開いたスレッドや Gem は同じメニューに表示される。
> **共通仕様:** すべてのアプリでスレッドが永続化され、再アクセス時に履歴が復元される (Chat / SuperChat / Canvas / DebateChat)。Gem は「ペルソナ定義」自体が永続化される。

## アプリ別 早見表

| アプリ | アイコン | 一言要約 | 典型ユースケース | このアプリで「できない」こと |
|--------|---------|---------|-----------------|---------------------------|
| **Chat** | 💬 | シンプルな 1:1 チャット | 質問・雑談・要約・翻訳・アイデア出し・添付ファイルの内容についての対話 | 専門エージェントへの自動振り分け / 自分独自のシステムプロンプト保存 |
| **SuperChat** | ⚡ | 複数エージェントの自動ルーティング | 「このコードをレビューして」「この SQL を最適化して」「Python で計算して」を 1 つの画面で | 複数エージェントの「順番に話す」討論 (DebateChat) |
| **Gems** | 💎 | 自分専用 AI ペルソナの管理 | 「議事録要約 Bot」「英文校正 Bot」など、独自のシステムプロンプト + knowledge を保存して使い回す | 内蔵 SubAgent の編集 (これは `agents/<name>/AGENT.md` 側) |
| **Canvas** | 🎨 | AI と一緒に HTML/JS ミニアプリを作る | 「タスク管理ボード作って」「グラフ描画ツール作って」を会話しながら HTML/JS で生成・iframe プレビュー | 静的 Web ページの公開 (本格的なホスティングではない) |
| **DebateChat** | 💬 (討論) | 複数エージェントが順番に発言する討論モード | 「この設計案、賛成派と反対派でそれぞれ意見ちょうだい」「3 人の異なる観点でレビューして」 | 1 人の AI と継続的に会話する (Chat / SuperChat) |

## アプリ詳細

### Chat

**役割:** 通常の 1:1 チャット。LangGraph の checkpointer でスレッド永続化。
**裏で動くもの:** `general-assistant` エージェント (`web_search` / `ping` / `db_query` / `attachments_list` / `attachments_extract` ツール利用可)。
**典型クエリ:**
- 「Python の dataclass と Pydantic の違いは？」
- 「先週の議事録 (添付済) を 5 行で要約して」
- 「Tavily で『LangGraph 2026 新機能』を調べて」(裏で `web_search` が走る)

**いつ使うか:** 軽い質問・調べごと・添付ファイルとの対話で、自動振り分けは不要なとき。

### SuperChat

**役割:** ルーター + 複数 SubAgent。クエリ内容から自動でエージェントを選択する。明示的に「`code-reviewer` で答えて」とエージェントチップで指定することも可能。
**選択可能エージェント:** `code-reviewer` / `sql-analyst` / `general-assistant` / `codeact` (詳細は [agents.md](./agents.md))
**典型クエリ:**
- 「以下の Python コード、レビューして」→ `code-reviewer` に自動ルーティング
- 「この SELECT 文を最適化して」→ `sql-analyst` に自動ルーティング
- 「数列 [1,2,3,4,5] の標準偏差を計算」→ `codeact` が Python を実行
- 「今日の天気を教えて」→ `general-assistant` が `web_search`

**いつ使うか:** タスクの種類が複数混ざっていて、AI に振り分けを任せたいとき。

### Gems

**役割:** ユーザーが作成・保存する AI ペルソナ。`name` + `system_prompt` + 任意の `knowledge` (参照テキスト) + `description` を持つ。SuperChat と同じインタフェースで会話でき、システムプロンプトに従って振る舞う。
**保存形式:** PostgreSQL の `gems` テーブル (`github_login` で所有者を分離、`is_public` で他ユーザーへの公開可否を制御)。
**典型ユースケース:**
- 「自社用ガイドラインに従う英文校正 Bot」(`system_prompt` にガイドラインを記述)
- 「議事録要約 Bot」(`system_prompt` で出力フォーマットを固定 + `knowledge` で社内用語集を埋め込み)
- 「特定 OSS のドキュメント Q&A Bot」(`knowledge` に README を貼り付け)

**いつ使うか:** 同じ前提・口調・出力フォーマットを毎回指定するのが面倒で、繰り返し使う指示を「テンプレート」として固定したいとき。

### Canvas

**役割:** AI に HTML/JS ミニアプリ (Canvas App) を生成させ、iframe でプレビュー、デプロイすると `/apps/<app-id>/` URL でホスティングされる。チャット側からは iframe 内のアプリへ **JSON-RPC 経由で操作指示** を出せる (`iframe-rpc.js`)。
**特徴:**
- 生成された HTML/JS は Canvas Editor で直接編集可能 (Monaco エディタ)
- iframe 内で `mcp_helper` 相当のツール (web_search / db_query / get_datetime 等) を呼び出せる
- デプロイ後は `apps/` MenuScreen から起動できる

**典型ユースケース:**
- 「タスクボードのプロトタイプを作って」(ドラッグ&ドロップ HTML)
- 「DB の `users` テーブルを表示する管理画面を作って」(db_query 経由でデータ取得)
- 「ストップウォッチ + ラップタイム記録ツールを作って」

**いつ使うか:** チャットだけで完結しない「触れる UI」が欲しいとき。本格的なホスティングではなく、社内向けのプロトタイプ・小ツール作成に向く。

### DebateChat

**役割:** 同じ議題に対し、複数エージェントが**順番に**発言する討論モード。1 ターンずつ進行し、ユーザーが介入することもできる。
**典型ユースケース:**
- 「マイクロサービス化案、賛成派 / 慎重派 / 中立派の 3 視点で議論して」
- 「SQL 最適化案を `sql-analyst` と `code-reviewer` 両方の観点で検討して」

**いつ使うか:** 一つの問いに対して「複数の独立した視点」を並列で見たいとき。

## 添付ファイル (📎) — 全アプリ共通

`Chat` / `SuperChat` / `Gems` / `Canvas` のチャット入力欄から **📎 ボタンでファイルをアップロード** できる (Phase 36/37 で実装、Phase 38 で worker 生成ファイルの DL も対応)。

| 添付できるもの | 何が起きるか |
|---------------|-------------|
| 画像 (PNG / JPG / GIF) | LLM が multimodal で画像を直接読む |
| テキスト / コード (.txt / .py / .ts / .md など) | 添付内容が会話コンテキストに展開される |
| PDF / docx / xlsx / pptx | `attachments_extract` ツールでテキスト抽出して読む |
| 任意のファイル | `attachments_list` で一覧化、execute_python / claude_code から参照可能 |

worker (execute_python / claude_code) が **生成したファイル** はチャット内に表示され、ダウンロードリンクから取得できる (ユーザー別ストレージで保持)。

> **DebateChat は添付対象外:** 討論モードは複数エージェントが順に話す設計で、添付参照のターン制御がまだないため、Phase 40 で除外している (#13)。

## メニュー画面 (MenuScreen) の構造

```text
┌─────────────────────────────────────────────────────┐
│ アプリケーション                                    │
│ ┌─────┐ ┌──────┐ ┌────────┐ ┌──────┐ ┌──────────┐│
│ │ 💎  │ │ 🎨   │ │ 💬討論 │ │ 💬   │ │ ⚡       ││
│ │Gems │ │Canvas│ │Debate  │ │Chat  │ │SuperChat ││
│ └─────┘ └──────┘ └────────┘ └──────┘ └──────────┘│
│  (固定)                       (apps/ から動的読込)  │
├─────────────────────────────────────────────────────┤
│ 最近のスレッド                                      │
│  - …                                                │
├─────────────────────────────────────────────────────┤
│ その他                                              │
│  - …                                                │
└─────────────────────────────────────────────────────┘
```

- **Gems / Canvas / DebateChat:** フロントエンドのコード (`MenuScreen.tsx`) に固定カードとして実装
- **Chat / SuperChat (+ 将来追加されるアプリ):** `apps/<slug>/APP.md` を起動時にロード、`GET /api/apps` で一覧取得して動的描画

新しいアプリを追加する場合は `apps/<slug>/APP.md` を作る (`agents/<slug>/AGENT.md` と同じ規約)。詳細は [../../CLAUDE.md § Architecture](../../CLAUDE.md#architecture) を参照。
